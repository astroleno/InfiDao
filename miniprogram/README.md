# InfiDao · 六经注我

原生微信小程序，WXML/WXSS + Canvas WebGL，无 web-view。测试 AppID：`wx5f0a423b84cafbef`。

## 当前交互

- **流动时只见全屏经轮**。五层水平经文共用竖轴，邻行交错、以不同速度缓慢旋转；中心放大清晰，上下逐渐缩小、模糊、隐去。沿用康熙字形、黑场材质与玻璃色散。
- **持续向上、无限环流**。内容批次不是流动终点；后续未到或没有合适新内容时，已加载的经文继续流动。显示窗口固定为 32 个复用位置，新内容在视野外的完整经句边界接入，不改变已经可见的行。同一句的分句稍靠近，段落之间稍展开。后台、用户停驻和减少动态效果仍按既有规则暂停。
- 经轮正文与展开的原文按词／单字提供入口，标点保持原样；点字词直接接续，点空白停驻或继续，拖动回看。经文不逐词加下划线，按下时反馈选中的范围。句意与此刻联系继续使用已有的少量下划线入口；解释仍只在停驻后出现，流动态没有底部短解区。
- 点击入口即锁定当前句和词义。等待时保留原画面，可取消；新句与字体准备好后，旧句退远、新句接入，来源词短暂标明来处，再继续流动。返回逆向承接；减少动态效果时不位移或缩放。
- 真机 Canvas 的局部 `x/y` 与原生阅读层的 `clientX/clientY` 统一换算，点击不再被误判为空白。接续失败在流动和停驻状态都可见；未连接时直接提供连接入口，提示可以收起。
- 停驻层提供「返回上条经文链」和「来路」；恢复原链的位置、行相位、停驻状态、原文展开状态与滚动位置。
- 一念、原文、自己的注脚均沿用原有入口。注脚只保存在本机，可删除和撤销。原文与人工整理/模型生成的联系明确区分。

上述布局与无限流动规则为用户 2026-09-23 的最新确认，覆盖早期提案中常驻短解和批次末尾等待的设想。

## 运行和服务

开发者工具直接导入此目录、编译 `pages/flow/index`，无需构建 npm。`flow/config.js` 的 `serviceOrigin` 留空时使用本地精选内容，可直接体验分叉与返回；精选内容不是个性化模型输出。

已有的 HTTP 在线模式使用仓库中的 Next.js 服务端：`POST /api/flow`，操作为 `open / branch / next`。服务端默认模型为 `deepseek-flash`，显式关闭 thinking；密钥只从服务端环境读取，支持 `FLOW_API_KEY / FLOW_BASE_URL / FLOW_MODEL`，否则复用 `DEEPSEEK_API_KEY / DEEPSEEK_BASE_URL`。旧 `/api/search` 和 `/api/annotate` 接口保持原合同。

端上业务已接入开发预览：检索、原文核对、经文链和历史放在小程序内部，DS 提供生成能力。当前测试号继续保留，无需微信云开发或自己的内容服务。预览打开 `pages/connect/index`，在手机上输入自己的 DS API Key，通过连接检查后进入真实生成流程；未连接时仍可使用精选内容。凭证仅保存在本机，可在连接页清除，不进入代码包；正式 release 环境禁用此连接方式。测试号手机预览若被域名校验阻拦，需在右上角菜单开启调试。打包与验证记录见 [手机预览](docs/2026-09-23-phone-preview.md)。

跳过连接后，轻点空白停驻，再点「一念 → 连接 DS」即可返回输入页。已有 Key 时入口显示「设置 DS 连接」。未修改连接时，点击「返回经轮」会保留刚才的经句、位置与一念草稿。任意经文字词的语境接续使用 DS；离线精选只返回已经人工核对的关系，其他词会提示连接，不以同字匹配任意经典冒充联系。

在线内容现在优先返回一个完整核验节点，再按游标补入后续；已读子链可恢复原位置，不重新生成。原生验证、延迟对照及生成质量的未通过项见 [逐段返回验证](docs/2026-09-23-progressive-flow-validation.md)。

HTTP 模式本机联调可在开发者工具中设置 `wx.setStorageSync('infidao-flow-service', 'http://127.0.0.1:3000')` 后重新进入页面；该覆盖只对 `platform === 'devtools'` 生效。用项目私有配置临时关闭 URL 校验，验证后恢复。移除该 storage key 即回到默认精选模式。仅继续采用该 HTTP 模式时，手机端才需要配置这份服务的实际 HTTPS 地址；端上业务路线无需该内容服务。外部模型请求仍受微信域名规则约束。

两种生成模式复用同一个内容核心，从本地语料选择和逐字校验引文、原文范围、来源与版本。模型负责检索线索、短解和候选联系；另一次校验过滤牵强关系、重复引文分叉及替用户作判断的解读。技术预测等不适合用古文回答的请求明确拒绝。无合适联系时不伪造新经文；原有流动继续。

生成会话目前保存在运行期内存中，最多 256 条、6 小时过期；重启后本机已保存的阅读仍可恢复，新的生成请求可能提示会话失效。端上跨重启的生成游标恢复仍需补齐；HTTP 多实例部署则需要共享会话存储。端上预览使用独立的阅读记录空间，不删除原有精选记录或个人注脚。客户端内容/字体总并发为 2，预取仅一层，缓存 24 个准备结果；后台和卸载取消请求。

画面窗口与内容批次独立：只在窗口边界复用槽位，时间轴周期不随批次长度改变。内存保留最近 12 段及被 32 个槽位引用的段落，旧阅读窗口存入本机；返回快照同时保存槽位映射。重复命中旧批次可以更新解读，但不会回退后续游标。

## 字体和资源

经轮、经句和完整原文使用同源字体：「润植家康熙字典美化体」及 Noto Serif SC 补字；解释、个人文字、输入与操作界面显式使用系统无衬线体。系统文案为简体中文，生成的句意与联系也要求简体；经文引用保持原字。Canvas 直接解析字体轮廓，不依赖 iPhone 的 Canvas 字体匹配。随包子集覆盖离线经文；动态分片同时注册到原生文字组件，原文层与经轮共用字库。

动态经文使用 `public/flow-fonts/` 的 13 个 WOFF 分片，约 2.42 MiB，共 6,165 个有效字符。端上预览将全部字体、11,722 条可用语料及其分词边界编入 10 个资源分包，每包小于 2 MiB，通过 `require.async` 按需加载；HTTP 模式继续从服务地址获取字库。字形会缓存，动画不逐帧绘字。语料另含 51 个无对应字形的私用区编码，内容核心不选择含这些编码的段落，不能猜字替换。全部 6,165 字已验证存在有效轮廓。

字体可由自己的 HTTPS 服务提供，**不要求 CDN**。分片文件名带内容哈希，与语料和字体版本一起记录。字体请求失败保留原生静读，不悄悄改换经轮字体。

重建需 fonttools 和原字体源：

```sh
python miniprogram/scripts/build-font.py /path/to/康熙.ttf /path/to/NotoSerifSC.ttf
python miniprogram/scripts/build-flow-fonts.py /path/to/康熙.ttf /path/to/NotoSerifSC.ttf
```

来源与许可记录保存在 `assets/fonts/NOTICE.txt`、`OFL.txt`、`manifest.js` 以及分片目录。正常运行和构建不依赖相邻 CoScroll 工作区。

业务核心、语料或字体分片更新后，在仓库根目录运行 `npx tsx scripts/build-wechat-local-core.ts`，重建 `flow/generated/` 与 `packages/local-*/`；此构建不读取或打包模型密钥。

## 验证

```sh
npm run check --prefix miniprogram
npm test --prefix miniprogram
npm run type-check:app
npx jest tests/unit/flow-service.test.ts tests/unit/flow-relations.test.ts --runInBand
```

`node scripts/check-flow-live.mjs` 是手动真实模型验证，会调用已配置的本地服务；默认不在 CI 中运行。测试语境见 `tests/fixtures/flow-contexts-v1.json`，输出默认在 `/tmp/infidao-flow-live.json`。

`npx tsx scripts/check-wechat-native-preview.ts` 验证实际打包的端上模式，需要已登录的微信开发者工具与本地 DS 测试凭证，会产生模型调用。它通过连接页完成接入，检查接续、分叉、返回、字体与无限流动，将手机的 `CanvasTouch` 格式传入实际页面处理器，并走原文组件的选择事件链。开发工具的触摸助手只支持浏览器坐标，不能用它冒充手机事件；实际原文点击另通过模拟器界面验证。结束后移除临时测试凭证并恢复开发工具配置，不清除阅读记录或个人注脚。

字词入口的数据范围、命中方式和验证边界见 [经文字词接续](docs/2026-09-23-classical-word-links.md)。

本轮验证记录及尚未完成的真机、网关、语义验收见 [BRANCHING-IMPLEMENTATION.md](docs/BRANCHING-IMPLEMENTATION.md)。模拟器成绩不能代替 iPhone/Android 真机结果。
