# 连续空间迭代

基线 `9c33bd0` 已按用户要求提交并推送。用户授权按评审顺序完成本轮，再提交推送。

## 设计与模块

- 全屏经轮、持续向上、相邻行交错慢转、康熙字形与色散保持；解释和链接仅在停驻阅读中出现。
- 新增显示队列：内容帧与固定数量的画面槽位分离。显示槽位保留当前及邻近行的身份；追加仅改视野之外的后续行，等待时继续循环已有内容。时间轴循环周期不随内容批次数量改变。快照保存槽位到原文行的映射，返回时恢复相同位置。
- `scene / timeline / renderer` 共享分句位置偏移：同一完整经句的分句稍靠近，段落边界略舒展；归中和点击命中使用同一个偏移。先以小幅参数对照，中心字号及竖轴不变。
- 分叉沿现有双截图承接增加向前/返回方向和来源词。旧句退远、新句进入时保留来源；减动时只淡接。动作编号继续取消过期截图及动画。
- 入口合同扩展 `surface`（quote / meaning / reflection）和经过核对的文字范围。原文引用范围、字序、标点不变；原生句意、解释及原文共用文本片段组件和 `frameId + anchorId` 分叉接口。旧数据未声明 surface 时按 reflection 处理。模型关系复核仍不能创造或更换目标。

## 验收

- 迟到批次、暂停时追加、前后拖动和多轮循环不替换已经可见的行；显示槽位有固定上限。
- 同句分句靠近，中心归中仍水平清晰；投影点击位置与渲染一致。
- 原文、句意、联系入口可实际分叉，返回恢复位置和阅读状态；无效范围不会变成链接。
- 原生模拟器验证实际点击、分叉、返回、连续追加与全屏流动；自动回归覆盖新边界。
- 本轮不部署在线服务，不以模拟器代替真机或独立语义质量验收。

## 实现与结果

- `ribbon-window` 固定 32 个槽位，保留可见行的出现次序和身份。迟到批次在视野外、完整经句之间加入；连续到达的批次不会覆盖仍未经过中心的新句。只有跨槽位边界才更新几何，字集不变时复用图集。
- 普通行距在原参数上缩小 10%；同句分句用最大 0.12 行的有界偏移进一步靠近。中心字号、字形、旋转方向、色散不变；命中、归中与绘制共用偏移。原文翻段选择最近的一次出现。
- 分叉承接仍共用原 renderer：旧图保留到新图解码，向前/返回相反的 28 px 位移，旧图轻微退远，340 ms 收尾。展开原文后的旧图锁定原来的位移；切后台若中断截图，前台重新生成匹配当前链的图像。减动时无位移或缩放。
- `linked-text` 接受精确的文字片段；`surface + start/end` 使用 UTF-16 范围，匹配失败退为普通文字。原文链接使用已核验的 `quoteStart`，不会误连同章更早出现的同词。默认精选内容三种入口均有覆盖；在线模型与关系复核共用同一合同。
- 小程序 75 项、服务端 10 项测试通过；JavaScript/JSON/页面检查、TypeScript 与变更服务端文件 ESLint 通过。含 1,000 步/201 段追加、倒拖和快照、范围重叠、Unicode、旧批次不回退游标、图片解码中断。
- 微信原生模拟器实际运行 30 次分叉 + 30 次返回：经句、位置、槽位、行相位、滚动和停驻状态全部恢复，WebGL 错误为 0，始终为 32 个槽位。精选链首句承接完成 422–462 ms，P95 459 ms；这不是手机网络成绩。
- 原生分别点击句意「先后」、原文「本末」、联系「本末」均能接续。迟到批次从 3 段增至 6 段时，可见行、当前进度均未变化。全屏流动已目检。
- 在线三语境初测显示模型偏向把入口全放在原文，因此调整了约束与示例。新复测在同一经句得到 quote / meaning / reflection 三种入口，文字范围均正确，句意入口分叉成功。该次 HTTP 首句事件 306 ms、完整分叉 8,635 ms；不得将前者称为手机可读时间。
- 初测的一次分叉返回 `RELATION_UNVERIFIED`（关系复核回复未通过结构校验），没有把未校验输出作为完成结果。它与语义相关率、真机网络和正式服务部署仍是在线验收的未完成项，不能以这次 UI 迭代宣称解决。
