## 模块与接口

- 现有 `open / branch / next`、全屏经轮、停驻、词入口和返回快照保持。
- 构建脚本将现有业务核心编译成小程序模块；完整可用语料与全部字体按小于 2 MiB 的资源包拆分，通过原生分包异步加载。
- 小程序适配器提供语料读取、安全随机 ID、取消信号与直连 DS 请求。模型请求继续共用现有并发预算。
- 新增仅供开发预览的连接页。用户在自己的手机输入 DS API Key，明确保存在本机，可清除；源码、资源包、二维码与日志不包含该凭证。正式 release 环境禁止启用该连接方式。
- 微信预览从连接页进入；准备资源和连接成功后回到原有经轮。无连接时原有精选模式仍可使用。
- 跳过后可从「轻点停驻 → 一念 → 连接 DS」再次进入；已有 Key 时同一入口用于管理连接。连接页提供返回经轮，未修改连接时保留阅读位置与一念草稿；清除连接后返回重新进入精选模式，避免旧请求继续使用已清除的 Key。首次生成出错时也提供连接入口。以上入口仅供开发预览，不占用流动主视觉。

## 验收

1. 完整语料、模型核心和字体从真实小程序包加载，无自动化运行时注入依赖。
2. 开场、后续、分叉、返回及取消行为回归通过，原有视觉不变。
3. 包体通过开发工具的实际预览检查，并产生手机预览结果或明确的平台阻塞。
4. 密钥不进入生成资源和预览代码；公开模型流量只发往官方 DS 地址。
5. 手机需由用户扫码体验，不能以模拟器结果代替真机实测。

本阶段沿用既有运行期会话与本地阅读快照。跨重启的生成游标恢复、释义质量独立验收和公开发布的凭证方案不冒充已完成。

## 连接失败定位

连接页按「验证连接 → 加载经文 → 保存连接 → 进入经轮」区分失败阶段。网络与 DS 状态通过共享错误模块分类，不显示服务端回显、请求头或原始异常。Key 验证通过后的分包失败不得再显示为凭证问题；资源准备有超时退出，重试保留输入。

开发预览中显示微信实际调试状态，提供显式开启按钮；不自动改变调试开关。错误下方提供不含 Key 的阶段、错误码、HTTP 状态及调试状态，便于手机反馈。公开发布仍禁用开发连接入口。

排查依据：开发工具在域名校验开启、调试关闭时，未携带 Key 的请求即返回 `request:fail url not in domain list`；同一时间，项目现有测试 Key 向官方 `/models` 验证返回 HTTP 200，包含 `deepseek-flash`。这证实本地复现的域名拦截及现有凭证可用，尚不能直接判定用户手机的失败原因。HTTP 分类参考 [DS 官方错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)，调试状态与开关参考 [微信官方 API 类型说明](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)。

91 项小程序测试通过，覆盖 HTTP 与网络失败、资源加载失败后的重试、不回显密钥、保存失败及仅由用户操作启用调试。实际打包代码再次通过真实连接、接续、分叉、返回和 WebGL 五项检查；本次开发工具联调临时关闭 URL 校验，验证后恢复，不能据此宣称手机白名单已经放行。模拟器调用调试开关后 `enableDebug` 仍为 false，因此页面会据实际状态提示从微信菜单打开并重新进入，不把 API 成功回调冒充已经生效。
