## 确定的设计

- 2026-09-23 用户纠正并确认：恢复原来的全屏经轮，不预留底部短解区。流动时只见经文；停驻后短解和可点字词随原有阅读层展开。竖直经轮、相邻行交错慢转、康熙字形与玻璃色散均保留。这项确认覆盖提案原先的常驻短解设想。
- 短解里的结构化入口直接分叉，按下即锁定经句和入口；等待时原句保留，准备好首句和字形后承接。返回恢复父链的经句、角度、流动状态和阅读位置。
- `chain-store` 保存链与可恢复快照；`continuation` 负责前台优先、最多两个并行请求、取消与去重。页面不承担这些调度细节。
- Provider 使用 `open / branch / next` 和可取消请求；每个经文节点有稳定 ID、真实原文范围、短解片段和可验证入口。缓存区分念头、义项、父节点、语料和模型版本。
- 服务端新增 `/api/flow`，使用既有语料与 DS 配置。原文只能取自语料；模型负责语义扩展、候选判断、短解及入口组织，不能自造引文。既有 search/annotate 合同保持不变。
- 2026-09-23 用户再次明确保留无限延展：经轮持续上升、循环流动。等待后续批次或无适合新内容时继续环流已加载经文，只有主动停驻才暂停。后续准备好后在向前阅读边界加入，不以批次末尾终止流动。历史按需恢复，图集和视图不随分叉增长。
- 从已使用的字体源构建语料覆盖分片，经文按需下载并直接解析轮廓；失败仍可原生阅读。沿用已有的轮廓绘制与可扩容图集，随包字库现为 741 字。
