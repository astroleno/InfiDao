## 范围与接口

- 将现有 `flow/service`、候选检索、关系复核和数据校验打包进小程序的真实 JS 运行时，保留 `open / branch / next` 合同。
- 仅替换 Node 专属能力：文件读取改为小程序文件系统；模型请求改为 `wx.request`；随机 ID 使用 `wx.getRandomValues`。
- 测试数据使用现有全部可用语料和字体文件。原文核对在本机完成，只有当前候选与公开测试输入发给 DS。
- 现有页面负责经轮、停驻、分叉、返回；本轮不修改视觉，也不启用新的正式默认模式。
- 开发验证的凭证只临时传入运行时，禁止写进小程序源码、构建包或报告。试验结束恢复私有域名校验、默认页面和临时文件。

## 验收

1. 本机全量语料解压、读取、解析和候选检索可运行；与现有算法对照结果一致。
2. 引用范围与出处在小程序内核对，伪造引用被拒绝。
3. 不启动本机 HTTP 内容服务，实际完成 DS 开场、分叉和后续；页面能显示及返回。
4. 单独报告文件大小、运行时间和未测项目，不将模拟器内存或响应时间当作真机数据。

## 已处理的接入问题

- 开发工具单次自动化消息不能承载完整资源包，探针分块传入内存，合并后一次写入原生文件系统，再解压。资源来自仓库本地文件，没有增加下载服务。
- 当前模拟器的文件系统返回跨 JS 运行环境的 ArrayBuffer，直接用 `instanceof ArrayBuffer` 会误判。通过微型字节探针确认后，本地资源适配器复制到当前运行环境的缓冲区，再交给既有字形解析器。仅创建 TypedArray 视图不发生复制，不能解决此问题。
- 现有字体渲染、经典文本和主视觉不需要为该迁移重做。本次实际从本地读取了 5 个字体分片，约 1.05 MB。

## 正式接入仍需完成的边界

1. 本轮为可复现的端上试验，默认入口仍是精选模式。尚未把生成模式作为日常默认入口发布。
2. 全量资源通过测试工具预装；正式包需要安排资源分包与加载，不能把测试预装当作手机分包验收。真机帧率、内存、弱网和长期阅读尚未验证。
3. DS 密钥只临时传入开发运行环境，不在小程序源码或构建产物中。开发验证临时关闭 private 域名校验。公开发布仍需确定模型请求凭证与合法域名；这两项不要求把检索、原文或经文链迁回服务器，也不能由客户端隐藏一个共享密钥来代替。
4. 沿用的核心会话目前在内存中，已验证同次运行内的分叉与返回；重启后恢复生成游标、离线状态和取消重试，需要在正式端上适配时继续补验。原有本地阅读记录不因此消失。
