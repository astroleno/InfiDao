# 原生小程序验证 · 2026-09-22

环境：微信开发者工具 2.02.2608060，基础库 3.17.3，iPhone 12/13 (Pro) 模拟器；测试 AppID `wx5f0a423b84cafbef`。所有应用画面来自原生小程序模拟器，无网页替代。

## 通过

- WXML、WXSS 独立编译；JavaScript 语法、JSON 和页面资源检查。
- 9 项自动测试：时钟与帧率、暂停/后台、拖动/回环、长帧保护、mock 主题路径、原文出处、竖直圆柱几何、上下对称焦点、画面仅含经典短句。
- 原生画面五层水平文字同轴排列；中心清晰，上下逐层变暗和模糊。首屏无标题、解读、出处、念头摘要等常驻内容。
- 轻点停驻，420 ms 归中；显示「一念 / 原文 / 继续」；从停驻状态继续。
- 原生 touchstart/move/end 拖动回看；手指按下停止自动推进，拖动后恢复流动。
- 在原生 textarea 输入「我想开始，却总在犹豫」，提交后选中 act 路径，自动流动，窗口关闭，GL error=0。
- 原文抽屉按需出现；完整原文、出处、示例解读分别展示；关闭后回到原进度。
- 真实模拟器点击「静静读一会儿」、下一段经文、继续；确认短句与序号变化，并恢复 WebGL 流动。
- 运行时调用 onHide/onShow 验证后台处理：隐藏时位置不变、绘制停止；恢复从原位置小步推进。
- 注入渲染异常后进入原生静读，可继续换段；点击继续后成功重建 WebGL，故障状态清除。
- 完整 mock 周期首尾图像比较：画面主体 586×975 像素，通道平均差 0.000115/255，最大差 2/255；无可见循环跳变。比较排除了手机状态栏和底部控件。

本地验证截图位于仓库忽略目录 `.codex-screens/`：`wheel-final.png`、`wheel-aligned.png`、`wheel-loop.png`。最终模拟器恢复自动流动。

## 边界

- 未做手机真机 GPU、帧率、功耗和字体一致性测试。30 fps、DPR≤2 是实现预算，不是实机测量结果。
- 320/390/430 宽度下的中轴和圆柱边界通过几何测试；原生视觉检查使用上列模拟器尺寸。
- onHide/onShow 是在原生运行时调用生命周期处理函数验证，未替代真机切换后台测试。
- mock 按已整理的路径循环，不是模型无限生成。DeepSeek 尚未接入；未上传、发布或提交代码。
- 一次将延迟和像素读取放入同一异步自动化调用的检查超时；已拆为独立生命周期调用及模拟器截图对比完成验证。
