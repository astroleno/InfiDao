# 公网连续阅读断点修复

## 目标与授权

用户要求完整走公网点词和连续阅读，直接修复打断体验之处，并再次确认钻石色散视觉。沿用 2026-10-19 已确认的阅读层、经轮、真实源文/关系核验、父链与本机存储架构及既有发布方式。新的公网费用上限已单独取得明确批准。

视觉：黑底、聚焦纯白、失焦/运动色散、少量原有金色。内容：经文与释义连续读，原文和注脚仍按需展开。交互：保留已到内容，等待就近可见，旧词重接与已访入口重放不要求重复操作。

## 公网证据

唯一 Ego 空间 26；桌面 1280×900、手机尺寸 390×844。通过实际键盘、点按和滚动操作，观测真实 `/api/flow` 响应；没有直接调用模型接口或更换访客来绕过限额。

1. 缓存经文点“止”，395 ms 返回 `CHAIN_EXPIRED`，须再点“沿此词重新展开”。
2. 重接 7,240 ms 收到完整帧；新文 11,082 ms 才显示。其间下载整章的 5 个字形分片，接口完成后额外等待 3,842 ms。
3. 主动滚到末尾，6,565 ms 后追加第二段，滚动位置保留；但两段原句完全相同：“缗蛮黄鸟，止于丘隅。”，出处分别为《大学》和《礼记·大学》。两份完整源文不完全相同，不能仅按源文 ID 或整章哈希排重。
4. 返回后再点相同的“止”，没有重放刚读过的分支，再次报 `CHAIN_EXPIRED`。已存子路径 `parentPathId` 正确，但服务端独立重接的 `chain.entry=null`，本机无法用该字段索引已访入口。
5. 再次展开被 `BUDGET_REACHED` 截断。既有部署上限为访客 5、IP 10、全站 20 次模型调用/UTC 日；本次重接通常需 3 次、续读需 2 次，确实只能完成两步。此限制不能通过动画或文案修复。
6. 首次恢复主动聚焦整块经文，出现大面积默认蓝色框；手机长经文点词时，等待区域在释义末尾，可能落到屏幕下方。

证据保存在 `.codex-screens/2026-10-20-flow/`，含实际请求事件、DOM 切换时刻、截图及当前测试路径的只读元数据。

## 修改模块与关键接口

- `shared/flow/controller.js`：仅对读者主动发起、尚未到新文的点词/续读，遇过期入口时从校验过的原句恢复一次。后台恢复、取消、源文版本不匹配、模型/额度错误不循环重试。独立重接仍是新服务端链，本机父路径保留。
- `FlowPathRecord.parentEntry?: { fromFrameId, anchorId, label }`：本机保存真实点击入口，与服务端 `chain.entry` 分离；已访索引优先用本机字段，兼容旧字段。原生存储适配读取相同可选元数据；不提高存储 schema 版本，不伪造服务端链身份。
- `service.ts`：将已读引文交给生成阶段作排除依据，并在生成/关系核验后按规范化引文拒绝跨出处重复、截短和扩长。重复不能假装已无内容或推进游标；不额外自动调用模型重试。源文仍逐字核验。
- 公网补验发现异写及来路重复：只对语料中确认的「缗蛮黄鸟／绵蛮黄鸟」作等价去重比较，模型同时收到两种已读写法；源文不改写。服务端 `StoredChain.priorQuotes?: string[]` 继承最近 64 条来路引文，沿用现有会话 schema 和限额；旧链按同访客的可用父链补齐。预备入口若指向已读句，沿其既有方向生成新句，不先发重复 head，也不增加模型重试。新分支、后续续读和预备入口统一排除已读引文；已完成分支仍重放原记录。
- 浏览器控制器：字体准备在后台进行，核验后的正文立即进入已有记录与阅读层。`WheelCanvas` 只为经轮需要的引文字形等待校验；追加帧也在字形就绪后安装，不把未准备的字交给渲染器。完整原文的额外字体按展开需求准备。
- `FlowRendererHost.setFrames(frames, activeFrameId?)`：暂停阅读时可原子保留正文正在读的节点，避免字体晚到后由旧画布反向重置阅读位置。
- `FlowWaiting` 增加紧凑形态，复用固定阅读头的出处副行展示状态及停止操作，不再把等待堆到长释义下面。初次加载、流动状态沿用现有光学等待。
- `ReadingLayer.focusOnEntry`：初次恢复不抢焦点；主动导航后把焦点放到可操作的词，保持键盘可见焦点，不给整块经文添加装饰框。滚动追加不抢焦点，手动继续可定位新段。
- 额度到限时说明新联系暂到上限、已读仍可回看，入口重放仍可用。费用配置保持原值，除非用户明确批准新的数值。

## 验收

1. 真实公网问题已复现；后续验证不得把模拟内容称作真实模型验收。
2. 相关回归覆盖过期入口的一次自动重接、取消保护、无错误闪现、重接分支重复访问零请求、跨来源重复引文拒绝且游标不变。
3. 延迟/失败字体时，正文不等字体；画布始终只绘制已核验字形，新段在就绪后接上，旧异步结果不能覆盖当前段或使滚动跳回。
4. 浏览器走原文、现代释义、生成联系点词，至少十步接续与后退/前进/重访、主动滚动/手动继续、取消、刷新恢复；核对 320、390、1280 视口及 reduced-motion。
5. 类型检查、改动范围 Lint、相关测试、生产构建和差异空白检查通过。用户未另行授权前不改公网费用上限，不创建分支/工作树/agent，不提交或推送。
