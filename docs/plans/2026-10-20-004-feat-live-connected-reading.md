# 随点生成与连续阅读

用户已批准：生成中继续点词，快速切换以最新选择为准，连续续读；保留钻石色散、黑底白光、简洁界面及现有 30/60/200 额度。复用当前工作区，不创建分支、agent，不提交或推送。本轮先完成实现、真实生成与可查看的效果。

## 模块与接口

- `shared/flow/controller.js`、`FlowExperience.tsx`：允许从当前可读内容打断生成；同一进行中入口合并，切换入口立即递增请求版本并取消旧任务。短暂合并快速连点，实际网络只追随最新选择；过时事件和异步 UI 收尾均不得覆盖新选择。恢复历史和暂停隐藏沿用现有语义。
- `flow/model.ts` 与流式 JSON 解析模块：保留单次模型调用计费、取消、超时、输出上限；增加真正的流式读取，只交付已闭合且验证格式的字段，不把不完整 JSON 或半句话当作可点击内容。
- `flow/relations.ts`、`service.ts`：独立关系核验仍是交付解释的必要步骤。核验流按经文身份、完整释义、完整联系依次交付；首个通过的节点一经显示不再改引文或已完成段落。正常点词为规划、生成、核验三次；已有方向/续读两次；保留原有一次格式纠正，发生时单独预留并计入额度。增加解释长度，减少生成预制入口的负担，所有词仍可按需展开。
- `FlowFrame` 增加可选的分段完成信息，`FlowEvent` 增加 `progress`；整体 `ready` 继续表示节点全部完成。前后端依据同一段落文本与原文身份验证选词，支持整体尚未完成、所选段落已经完成的状态。
- `session-store.ts`：按现有租约持久化进度后才发送事件，保留并发创建的子分支。取消后已读内容可恢复，未完成续读从其原操作恢复，避免跳过半段或重复创建节点。已完成操作重访复用结果；取消前已发生的调用照常计费，补全未完成节点仍需要生成与核验。
- `provider.ts`、`prepared-provider.ts`：消费和转交进度；预备期间不改变页面，读者正式续读后接管同一请求并接收后续进度。缓存只加速同一语境，不限制可点的词。
- `ReadingLayer.tsx`、共享选词模块：完整释义和联系即刻可点；续读在原阅读区追加，保持滚动、键盘焦点和来路。色散渲染和中性白灰样式沿用上一版。

## 验收

1. 快速选择不同词、同词重复、迟到事件、取消与历史恢复的状态回归；点击不丢失、不串方向。
2. 实际传输被拆成任意字节、字段和 UTF-8 片段时解析正确；半段、伪造选词、变更的已交付文本被拒绝。
3. 服务端进度先落库再可点，生成中从经文及已完成释义接新分支；来源和独立关系核验保留。
4. 续读接管预备后仍能逐段到达；取消、失败不清空已读内容，不移动阅读位置。
5. 运行相关回归、类型和 Lint；通过一个真实模型会话核对新点词、生成中转向、快速切换、连续续读、返回。区分真实模型结果与受控回归，不用精选或假流式效果代替真实生成。
6. 截图检查移动和桌面的钻石色散、纯白焦点、白灰 UI；保留可查看的本地结果。真实生成记录实际调用和耗时，不提高任何生产额度或切换供应商。
