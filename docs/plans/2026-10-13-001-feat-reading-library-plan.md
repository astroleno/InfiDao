## 新评审核对与简洁约束

依据：当前源码、用户提供的 `.tmp-shots/mobile-flow.jpg`、公网 `/infidao` HTML。顶栏经文干扰、来路不可点、触屏键盘提示、未隔离 hover、38px 顶栏按钮以及主题色不匹配均有依据。

- 保留黑金体系，用顶栏渐隐遮罩、44px 触控区、设备适配文案、可点来路和轻量首次提示修正实际问题。
- 加载态只使用品牌文字与真实阶段提示；不增加印章、呼吸动画、百分比或进度计数。
- 基础字体通过与完整性校验加载器相同的 `fetch` 资源类型提前下载，文件清单由发布生成器输出。
- WOFF2 不直接转换：当前 `miniprogram/flow/vendor/opentype.js` 明确要求外部解压器，简单替换会破坏经轮字形解析。`public/flow-fonts` 是生成器输入，不能当作过期文件删除；旧发布资产也不在此次清理范围。
- 12 秒首次加载和“减少 10 秒”没有可复现的分阶段数据，不作为本轮性能结论。字体总目录大小不等于每次首屏下载量。
- 暖棕、朱砂与关于入口属于视觉或功能扩展，本轮保留现有风格和单一温故入口。

## 目标与交付范围

完成「读一句 → 收藏或留注 → 关闭页面 → 从温故找回 → 在原位置继续读」闭环，并改善接续词与注脚入口的可发现性。

1. 顶栏新增「温故」，面板提供「最近阅读 / 收藏 / 注脚」三项切换。
2. 最近阅读按路径展示，按最近阅读时间排序，显示经句摘要、出处和时间；分批显示。
3. 停驻阅读支持收藏、取消收藏与直达注脚。收藏按经句身份去重。
4. 注脚支持新建、编辑、删除、撤销删除；温故中可查看全部注脚并回到对应经句。
5. 用户主动点击后，将全部注脚导出为 UTF-8 Markdown，包含出处、经句、注脚和时间。
6. 接续词显示克制的常驻标识；首次阅读提供可关闭的轻提示；触屏优先显示触控说明；改善经文分词及标点换行。

视觉沿用现有黑金配色、字体和面板语言。手机面板占用可用高度、内容独立滚动；桌面使用限宽面板。空列表直接说明用途和返回方式。

## 数据与接口

### 本机存储兼容

- 保持现有 IndexedDB 数据库版本 2 和 `paths / notes / meta` 三个存储区。
- 收藏存放于 `meta` 的独立命名空间 `library:bookmark:<quoteKey>`，结构包含 `kind`、`key`、经句身份、`pathId`、`chainId`、`frameId`、经句摘要、出处、阅读快照、创建和更新时间。
- `quoteKey` 由 `sourceId + corpusVersion + textHash + quoteStart + quoteEnd` 无歧义编码得到。同一句在不同阅读链出现时只收藏一次，保留所选阅读上下文。
- `PersonalNote` 新增可选 `pathId` 和经句出处快照；保留旧字段和原有 ID。编辑只更新文本和 `updatedAt`。
- 旧注脚通过 `chainId + frameId` 匹配已保存路径；无法匹配的仍能查看、编辑和导出，并标明原阅读记录不可用。
- 阅读快照新增可选 `activeFrameId`；旧快照继续按现有位置恢复。
- 继续使用现有写入队列、会话缓存和删除标记。保存失败须明确显示「仅本次可用」或失败原因，不能声称已长期保存，也不能清空未保存的输入。
- 不因列表分页而删除本机历史；首次提示状态使用独立 `meta` 键。

### 关键接口

```ts
listPaths(): Promise<FlowPathRecord[]>
listBookmarks(): Promise<Bookmark[]>
saveBookmark(bookmark): Promise<PersistenceResult>
deleteBookmark(quoteKey): Promise<PersistenceResult>
listAllNotes(): Promise<PersonalNote[]>
updateNote(id, text): Promise<PersistenceResult>
loadLibrary(): Promise<{ paths, bookmarks, notes }>
openSaved({ pathId, frameId?, snapshot?, notes? }): Promise<boolean>
exportNotesMarkdown(notes): string
```

实现使用现有 IndexedDB 列表读取，在 `library.ts` 汇合旧注脚关联；面板每次显示 20 项，通过「再看一些」继续显示，不删除历史。`PersistenceResult` 保留 `persisted` 与错误信息。现有 `listNotes(chainId, frameId)`、新增注脚、删除和撤销接口继续可用。

### 返回阅读规则

- 打开温故先记录当前阅读位置并暂停经轮；关闭后恢复进入面板前的状态与触发按钮焦点。
- 从最近阅读进入时恢复该路径的最近位置；从收藏或注脚进入时定位对应经句并停驻阅读。注脚入口进一步定位注脚区。
- 打开目标复用控制器恢复流程，导航采用 `push`，让浏览器返回可回到此前路径；异步旧结果不能覆盖新选择。
- 共享控制器增加可选 `resumeIncomplete` 恢复参数，默认维持现有行为。温故显式设为 `false`：打开本机记录不自动发起模型请求，未完整内容由用户点击继续或重试。
- 目标路径或经句失效时显示具体原因，保留当前阅读及注脚内容；不悄悄定位到其他经句。
- 模态面板互斥；打开时限制背景交互，支持 Escape、焦点循环和关闭后焦点恢复。

## 验收标准与拟执行验证

1. 阅读、收藏、留注后刷新或关闭重开，温故可找回原句、阅读位置和注脚；取消收藏后刷新不再出现。
2. 同一经句重复收藏不产生重复项；两条不同阅读链的注脚不会串到一起。
3. 注脚编辑保持 ID 和创建时间；取消编辑保留原内容；删除和撤销正确；导出的中文、换行、出处与经句准确。
4. 用版本 2 旧路径和旧注脚验证兼容；失去原路径的注脚仍可编辑和导出。
5. 模拟存储拒绝、延迟返回、连续切换记录与未完成链：有准确提示，无内容丢失或旧请求覆盖；打开温故记录不触发生成请求。
6. 在 320、390 和 1280 像素宽度验证列表、阅读、编辑、空态和长文本无横向溢出；验证键盘、焦点恢复与减少动画偏好。
7. 按上述范围补充并运行存储、恢复、导出相关测试，执行类型检查和构建，并以本地内容完成浏览器交互与截图核对。
8. iPhone / 微信软键盘、中文输入法和系统读屏的实际设备验收单独报告；桌面模拟不能记为真机通过。
