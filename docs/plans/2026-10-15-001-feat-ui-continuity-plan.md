# 界面一致性与阅读连续性

用户于 2026-10-15 要求核对整体 UI，并直接迭代 UX。依据当前代码、上一轮实际界面截图和本地浏览器验证；沿用已确认的钻石色散与高度简洁 UI。

## 目标与设计

- 视觉：共享中性黑底、白色正文和灰色辅助信息，金色只标识操作与当前状态。首页移除暖棕背景和朱砂装饰；经轮的动态色散继续由原渲染器提供。
- 内容：经轮、原文、输入与温故维持现有结构。温故标题/分类固定，列表独立滚动；空态与操作反馈留在原面板。
- 交互：输入一念时暂时停驻，关闭后回到此前状态；减少动画仍停驻。注脚新增/编辑草稿按原经句/注脚分别保留，切换、收起和刷新不会无声丢失。保存成功才清理对应草稿，保存期间的新输入保留。

## 模块与接口

- `globals.css`、`layout.tsx`、`flow.module.css`：共享 `--void / --beam / --halo` 与正文/辅助/操作颜色，兼容首页原有语义令牌，主题色一致。无需更换字体、渲染器或新增依赖。
- `useFlowDialog`、`SeedSheet`：统一焦点隔离/返回，支持按打开状态启用；中文输入法组合期间 Escape 不关闭。
- `FlowExperience`：记录输入面板前暂停状态，关闭与成功打开新内容分别处理；沿用现有控制器与取消接口。
- `LibrarySheet`：固定标题分类，标准 tabs 键盘切换和单个 tab 焦点，分类切换回到列表开头。
- `storage.ts`：在现有 IndexedDB v2 `meta` 中使用独立 `note-draft:` 命名空间，`loadNoteDraft / saveNoteDraft / clearNoteDraft(expected)`；不迁移数据库，不发送草稿给服务端。
- `useNoteDraft`、`NotesPanel`、`EditableNote`：复用异步草稿逻辑；迟到的读取不能覆盖新输入，旧保存结果不能清除更新的草稿，持久化失败如实提示。

## 验收与边界

核对首页、经轮、原文、温故和输入的色彩/焦点/表面一致性；320、390、1280 像素与短横屏无溢出，长温故列表的关闭/切换始终可达。验证新增和编辑草稿恢复、保存竞态、存储失败、输入面板暂停/恢复、键盘 tabs 与输入法 Escape。执行相关测试、类型检查、Lint 和构建；浏览器用本地精选内容，不调用模型。

仅本地实现和验证，不提交、推送或发布。保留已有修改与截图，不增加功能导航或新渲染系统。

## 实施与验证记录

- 首页与经轮共用光学语义色；原有 Tailwind `paper / ink / seal` 名称保留为兼容别名，旧 stone 工具色映射到中性灰。扩大首页文字场的中央留白，避开标题和输入区；阅读层加强遮挡，正文、原文、注脚和输入框回到白色与灰色。
- 保留的辅助文字提亮到可读灰阶，避免直接套用默认中性灰导致小字变暗。经轮辅助文字与纯黑底的令牌对比度为 8.24:1，正文为 14.98:1；这不是全站所有色对的实测声明。发布资源摘要纳入 Tailwind 与 PostCSS 配置，确保样式配置变化也生成对应候选。
- 温故标题和分类位于独立滚动区域之外；tabs 使用单个键盘焦点和左右/Home/End 切换。浏览器实测 20 条首批列表加分页入口，列表可滚动，滚到末尾后标题和关闭入口位置不变，无横向溢出。
- 输入一念时记录并暂停此前状态，返回时恢复；新一念准备好后停驻在首句。输入法组合期间 Escape 不关闭面板。焦点隔离与返回复用同一实现。
- 实际浏览器验证：流动态打开一念后暂停为 `true`，关闭后恢复为 `false`；输入的注脚草稿已在本机 IndexedDB 中读回。
- 最终视觉核对发现原有 `overflow: hidden` 外层仍可被聚焦/`scrollIntoView` 程序滚动，可能挤走阅读标题。改为不可滚动的裁切外层，保持正文、原文和温故列表各自滚动；该修正纳入最后候选并重新构建。
- 新增及编辑注脚草稿在现有 v2 meta 存储区保留。恢复延迟不覆盖新输入，旧保存结果不清除更新草稿，持久化失败提示真实状态。修正删除注脚时过早尝试聚焦禁用按钮的问题。
- 31 项相关测试已分别通过（草稿 5、阅读键盘/焦点 3、存储 14、一念面板 5、温故面板 4）。机器负载导致部分异步测试超过默认 5 秒，本轮复跑为这两个套件提供 30 秒执行上限，未修改测试源码中的时间限制；此结果不作为性能结论。
- 应用和脚本类型检查、改动范围 Lint 和差异空白检查已通过；`372bcf3b11400519` 完整构建（含内置 Lint/类型检查、12 个页面及 standalone 打包）通过。随后仅修正 CSS 外层裁切，代码与类型接口未变；最后打包使用项目既有受限资源模式，复用已通过的代码检查，避免机器高负载下重复类型检查。最终候选与生产复核结果见下。
- 经过实际经轮流动与键盘回看，回到原句后草稿已恢复；其他经句输入区保持独立。界面异步取回草稿后核对，不把切换当帧的空输入区误记为丢失。
