# 接续召回、关联质量与首句可读

基线为 `5672d5e`。Astra 定评测口径并独立验收，Sol 实现。三个批次在现有分支单独提交和推送。

## 第一批 · 基线

- 在既有 `runFlow` 的本地评测调用中捕获实际候选和阶段数据。Top40 来自 `candidatesFor`，Top12 使用实际发送给生成模型的原文窗口。以来源 ID、语料版本、文本哈希和 UTF-16 半开范围定位，含重复文本时使用所选窗口的确切位置。公开事件、会话记录与正常服务的日志沿用原接口。
- 提前封存新题、可接受证据组和固定检索计划。覆盖一念、首层点词、深层点词和续读，区分典籍与诗词范围，保留领域外负例。旧题用于回归。报告 Hit@40、Hit@12 和已标注证据的宏平均召回，拆出未入池、筛选丢失、窗口截断及末端不合格。强制经句、无适用证据与缓存直达单独记录。固定计划检索与真实模型运行分列。
- 末端关联按古义与原文准确、实际回应当前处境或所点词、相对已读内容有具体推进评分。Astra 在看不到版本、排名与预置证据组的提交包上独立评审。合适的题未交付记失败，领域外拒绝另记。
- 点词在 390px Chromium 的实际阅读路径计时。记录点击反馈、新经句事件、「去读」可用与首句在阅读区可读。屏外结果由测试在入口可用后主动点击，单独报告这段人工动作；冷接续、已读重访和预备续读各用自己的分母。报告中位数及慢端，少于 20 次时以原始样本解释尾部探索值。
- 固定语料和匿名合成处境运行。真实调用使用本地既有设置和隔离会话，整轮最多 60 次模型调用并记实耗，公开站点和日限额维持现有配置。离线用例不发模型请求。先保留可复现记录、盲评结果与配对尺寸。

## 第二批 · 召回

第一批的损失主要发生在入池。固定诊断题上单独检索焦点词法和本地向量均未找到新增标注证据。真实深层「择」的五条规划线索来自同一部书，其中两条是当前引文的分句，两个标注证据组都未入池。

在 `lexemes.ts` 的既有 `planWord` 调用中，让可检索原文承接所点词的义项，并在可确定出处时加入来自另一典籍或作品的线索。当前引文或分句由上下文提供。保留贴切的同书线索及 2–8 项协议。用 `FLOW_PROMPT_VERSION` 区分新旧规划及语义缓存。已核验锚点的快路、出处逐字核对、独立关联核验和调用额度取用既有接口。

对照四个已封存的真实点词，其中两项是留出。比较实际 Top40／Top12、被挤出的标注证据、同条件匿名评审及调用数。至少有新增可信证据进入送模窗口或有盲评净改善，并检查既有命中、错误及出处。

候选未通过上述门槛。末位窗口的保守补证预试也没有净收益。运行版沿用 v17，第二批交付配对数据。 [配对验收](../qa/2026-11-25-flow-recall-iteration.md)

## 第三批 · 点击到可读

第一批的即时反馈为 7–11 ms。三个直接到读区的点词结果，标题出现之后仍有约 850 ms 墨迹等待。第三批针对这段浏览器等待。采用既有浏览器 120 ms 点词请求延迟与当前取消边界。

`FlowExperience.present` 核对当前点选和成功结果的来路后，对 `FlowArrival` 标注点词来源。`FlowStream` 沿用原阅读区和遮挡判定。当开篇已交接、目标已在读区时，对该目标首句调用既有 `InkMotion.finish`。阅读层仍推进该段位移、释义和回响动效。屏外继续显示「去读」，读者触发后才定位。普通续读及首篇出水沿用各自动效。

对照同一核验后经句、设备条件和服务器缓存状态，记录点击、标题可见、首句可读、去读及可访问焦点。真实冷点词另列，小样本尾值用作探索。验收覆盖遮层、切换与取消、低动态与原生字、普通续读与开篇，以及已有模型预算和调用。

390 × 844、DPR 3 的 Chromium 对照同一服务端缓存引文，每版 20 次。点词到首句可读的 P50 / P95 为 1.005 / 1.028 秒 → 0.187 / 0.203 秒。标题出现到可读的 P50 为 833 → 17 ms。缓存样本不触发模型调用。恢复提示与加速资格分开后，正常点词的判定条件等价，最终源码额外 4 次缓存复验为 176–202 ms。

最终源码的四次冷点词全部交付，引文位置均与原文一致。首句可读分别用 3.946、4.545、4.309、4.521 秒。三个直接进入读区的标题在出现后 16–17 ms 可读，屏外项仍由测试者主动「去读」。每次冷点词均调用模型三次。两组冷样本的端到端差异同时受到模型及屏外定位影响。

固定的真实计划在最终版离线重放，候选与评分逐项一致。四个重新生成的冷样本中，预标证据 Top40 / Top12 命中为 2/4 和 0/4，独立关联评分 3/4 通过。真实规划有波动，盲评也识别了预标之外的合适经句。整轮调用共 50 次。
