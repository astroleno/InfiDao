# 六经注我：App 感交互迭代

日期：2026-10-28。状态：本轮实现及独立复审已完成；验证结果与局限见[迭代记录](../reviews/2026-10-28-app-feel-iteration.md)。

## 目标与边界

承接 [双视角评审](../reviews/2026-10-28-frontend-uiux-flow-review.md)，让读者操作后的反馈、工具进出和返回行为连贯可预期。继续使用现有 Next.js / React 网页架构、持续阅读图和浏览器存储。

保留黑底、水膜与火彩画质、康熙经文字体、64% 阅读列、短句分行、交替显现、20 / 16 / 12px 与 400 / 500 层级。自动奔流、手动滚动恢复的既有规则继续有效。本轮不加入速度设置、底部常驻导航、强制输入或新的生成请求；不调整模型、额度、服务端或数据格式。

## 本轮设计

| Before | After | Why |
| --- | --- | --- |
| 注脚正文与导出、删除横排，手机正文约 9.6px | 正文独占一行，操作另起可换行区域；编辑态和长文本也占满阅读列 | 自己的理解应与经典一样可读 |
| 打开注脚只展开，焦点仍在菜单把手 | 将所属经句的注脚标题带入可读区域；键盘进入标题，触屏不自动弹键盘 | 菜单动作自然接到目的地 |
| 收藏后没有可见确认 | 在阅读层显示短暂、安静的成功／取消反馈，失败时准确提示；保留读屏状态 | 一次操作即可确认结果 |
| 点词结果在下侧，原处等待消失 | 新首句不在主要阅读区时，显示“已接续 · 去读”；仅主动进入才定位新内容 | 保留原读点，也让回应可发现 |
| 菜单在松手后突然入场、关闭直接隐藏 | 边缘拖动跟随手指，释放后收束；开关可反向中断，键盘立即响应，减少动态效果直接切换 | 工具和阅读场共享空间连续性 |
| 一次浏览器返回同时收起释义并退出分支 | 临时面板占用自己的返回层，先关闭最上层，再返回阅读路径；关闭按钮与 Esc 使用同一关闭入口 | 返回只退出眼前这一层 |
| 首次提示含糊，阅读来路需记忆 | 明确“点空白停驻”；现有菜单按需显示所选词／一念及“回到来处” | 把读者的选择连接成可理解的来路 |

## 模块和关键接口

- `NotesPanel.tsx`、`EditableNote.tsx`：正文和操作区域分离；保留保存、编辑、删除、撤销与纪念卡接口。新增可定位标题标记，避免强制输入焦点。
- `FlowStream.tsx`：负责注脚定位、分支到达提示和主动进入的滚动／焦点交接。定位后同步逻辑滚动与光学测量，避免下一帧回弹；手势取消不得触发词分支。
- `FlowMenu.tsx`：沿用受控 `open` / `onOpenChange`，增加可中断的表现状态；关闭与下一任务交接时，不用退出动画遮挡新任务或把焦点抢回把手。使用项目已有动效依赖，不新增依赖。
- `useFlowDialog.ts` 与新增的阅读浮层历史模块：统一登记最上层临时面板、清理焦点隔离及关闭行为。阅读面板的浏览器历史状态与阅读路径分开命名，继续保留 Next 自身状态。
- `src/lib/flow-browser/history.ts`：识别仅属于面板的返回，避免误调用阅读路径恢复；实际阅读导航仍由现有控制器负责。不得用不断补推历史的方式阻止退出。
- `FlowExperience.tsx`：把真实收藏结果转成状态反馈；传递已存储的选择来路和 `returnToParent`，管理真实分支首句到达信息。只使用本次请求结果，不提前显示成功。
- `flow.module.css`：统一操作命中、按压反馈、安全区与短文本换行；仅工具层使用 transform / opacity，保留核心渲染参数。

浮层历史需要覆盖：抽屉到释义／添一念／温故／纪念卡的替换、关闭按钮、Esc、Back、Forward、首次访问、分支返回、快速开关以及面板内完成阅读导航。面板退出不得丢草稿、撤销存储动作、重发模型请求或改变阅读位置。关闭后的历史空层需要消除，避免多按一次返回。

## 验收标准

1. 320 / 390px 和桌面下，短长注脚及编辑态可正常阅读；操作可换行，保留字号和阅读列。
2. 从当前段或较早段打开注脚，标题可见、焦点正确；触屏不强制弹键盘，保存与取消不丢原经句。
3. 收藏及取消有一次明确反馈；持久化失败不显示成功。
4. 新分支在屏外时有主动到达入口；进入及返回准确，取消与失败不留下假成功状态。
5. 菜单拖动可取消、可反向，纵向滚动不误开；关闭、快速重开和键盘操作焦点不丢失。
6. 面板内第一次 Back 关闭当前任务，下一次才退阅读分支；显式关闭不留下空返回层；Forward 不制造多余面板或改变经句。
7. 既有水膜、字体、画质、逐字显现和自动奔流规则保持；核心渲染代码和参数不因工具层改动而降级。

## 验证与交付

确认后在本机实现，使用后台、无模型调用的固定数据验证重点状态和窄屏画面；必要的源码检查及交互检查限于本轮改动。不抢前台，不提交付费手写任务，不扩大测试额度。

本轮交付代码和变更记录。提交、推送及公网发布另按用户明确授权执行；本轮不把 App 感迭代写成稳定 60 FPS 或几十轮长读已经通过。
