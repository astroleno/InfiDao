# 钻石色散阅读界面 · 本地预览

用户已确认并要求先迭代一版查看：黑底、白光、钻石色散，所有金色方案作废；经轮放慢，经文、释义和此刻的联系在同一阅读区分清主次。沿用当前工作区。

## 目标与模块

- `globals.css`、`flow.module.css`：操作、焦点、选词、提示、输入和温故统一为中性白灰；光谱仅来自加载光束和经轮光学渲染。经文最大且清晰，释义为正常正文，联系与出处退为次级。
- `ReadingLayer.tsx`：经文、释义、联系连续呈现，减轻重复标识，增加单屏有效阅读空间。续段追加保持视口；用户明确续读时只转移键盘焦点，不强制滚动。
- `renderer-host.ts`：浏览器自动流速为当前的 65%，拖动、惯性和手动浏览不变。
- 共享 `renderer.js`：沿用 `opticalProfile`、`reading` 和 `readingAmbient` 接口。聚焦经文保持纯白；停驻时周边失焦经文保留静止、低亮度色散，继续时自然展开。小程序默认光学模式不变。
- `next.config.js`：修正开发预览错误复用生产静态资源长期缓存的问题；开发资源使用 `no-store`，生产版本化资源沿用长期缓存，保证本地看到最新样式。

## 接口与范围

复用现有 `FlowFrame`、选词、阅读存储和接续接口。本轮实现已确认的视觉、节奏与内容层级，不改变服务端生成、资料库、模型额度或计费，不宣称已实现完整预制关联图。交付为可查看的本地预览，尚不发布公网。
