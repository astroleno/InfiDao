## 发布产物

### 网页字体独立资源

网页从版本化字体目录读取两份基础 WOFF，移除 JS 内的 base64 字体。构建时 `scripts/web-flow-font-assets.cjs` 将原生字体逐字节导出，网页清单新增 `baseFonts` 与 `baseCharacters`，并由基础字体元数据及原有分片清单共同生成新版本号。原生 `public/flow-fonts` 清单与小程序接口保留；`glyph-core` 负责共用轮廓算法，Next 的 Webpack/Turbopack 别名将网页图集连接到浏览器字形实例。

网页先校验文件大小及 SHA-256，再把同一份字节交给文字字体与经轮绘制；缺少 WebCrypto 时明确失败，不跳过完整性校验。基础字体已覆盖的字符不再重复下载分片。基础字体和分片共用最多 3 个下载槽位，每次请求（含响应体）8 秒超时；CDN 清单失败后整次准备使用同源目录。失败时保留静读并提供“重试字体”，重试仅加载资源，不生成经文，保留当前停驻状态。

发布打包与 standalone 组装均须包含 2 份基础字体、13 份原有分片和新清单。CDN 包清单为 16 个字体资源条目，另有一份发布清单；不要复用旧字体版本目录或覆盖旧对象。具体版本和内容哈希以本次构建清单为准。

本地生产构建对照当前公网页面：HTML 引用的 JavaScript 从 10 个、1,389,738 字节降为 9 个、1,040,601 字节，减少 25.1%（解压后的资源大小，不代表网络传输量或首屏耗时同比下降）。两份基础字体共 259,564 字节，作为独立二进制加载；741 个基础字符的轮廓逐一与小程序一致。Chromium 的 320、390、1280 像素视口已检查；注入字体失败后可重试，停驻状态保留、无新增内容请求。该检查使用本地精选或模拟内容，不能替代真实模型效果、iPhone Safari 或微信真机验收。阅读滚动区右侧增加 8 像素留白，避免滚动条遮挡文字边缘。

### 阅读额度预留

代码在共享 Redis 预算中为当前阅读请求预留必需的模型调用：新心事、无预备入口的选词或重新展开通常需要规划、生成、校验共 3 次；已有方向的接续、预备分叉与补全需要 2 次。已完成请求先重放结果，不做模型额度预留；请求频率和并发限制仍适用。预留不足时在模型工作与首句发送前结束，不提高现有上限。

预留与扣费使用同一 CAS 事务；全站、访客和 IP 的剩余额度均扣除其他活跃请求的预留。仅实际调用累加每日用量，消费一次预留即转成一次实际用量。请求结束、取消或 120 秒租约过期归还未用预留，已调用次数不会退回。跨 UTC 日保留仍有效的预留、重置实际日计数。可选格式修复须另预留一次；不足时返回原格式错误，不占用关系校验预留，也不跳过校验。

存储增加可选 `active.*.reservedModels` 字段，兼容已有预算记录。发布须停止旧进程后启动新进程，避免旧版本不识别预留而占用已保留额度；现有单进程 systemd 部署满足这一方式。预算错误提示保持现有产品文案。本地回归和隔离 Redis 可验证记账规则，但不能替代上线后的真实阅读验收。

### 可选阶段计时

代码支持在服务端设置 `FLOW_TIMINGS=1`，每次阅读请求输出一条 `[flow-timings]` JSON 摘要；默认关闭。摘要包含操作类型、总时长、成功/失败，以及 `plan`（方向规划，可能同时准备索引）、`retrieve`（候选检索）、`generate`（节点生成，含格式修复）、`review`（关系校验）、`model`（单次模型网络请求和解析）的耗时。模型耗时嵌套在各业务阶段内，不能再次累加；总时长从阅读服务开始到结束，不含入口身份校验、请求额度租约获取和网络传输。已完成结果重放通常没有阶段样本。

不记录心事、经文、模型正文、会话/请求标识、IP、密钥或错误正文；计时失败不改变阅读结果。不新增模型调用，不改变额度。上线后须在现有额度内采样才能判断等待瓶颈；本地模拟验证不能代表真实模型耗时。

在私有环境文件或密钥管理器中配置，勿提交：

| 变量 | 用途 |
| --- | --- |
| `FLOW_PUBLIC_ORIGIN` | 预发布 HTTPS origin，精确匹配浏览器 Origin |
| `FLOW_SESSION_SECRET` | 至少 32 字符的随机会话签名密钥；同一预发布集群保持一致 |
| `FLOW_REDIS_URL`, `FLOW_REDIS_NAMESPACE` | 持久 Redis 和与现有业务隔离的命名空间 |
| `FLOW_API_KEY`, `FLOW_BASE_URL`, `FLOW_MODEL` | 仅服务器使用的模型凭据、地址和模型 |
| `FLOW_MAX_ACTIVE_SITE/OWNER/IP` | 同时进行的全站、访客、IP 上限 |
| `FLOW_REQUESTS_MINUTE_SITE/OWNER/IP` | 每分钟请求上限 |
| `FLOW_MODEL_CALLS_DAY_SITE/OWNER/IP` | 每 UTC 日实际模型调用上限，包括规划、纠错和释义调用 |
| `FLOW_NATIVE_HTTP_ENABLED` | 确认小程序 HTTPS 合法域名后再开启原生 HTTP Provider |
| `NEXT_PUBLIC_FLOW_FONT_CDN_BASE` | 构建时固定的 CDN 字体版本目录，留空时使用同源资源 |

九项限额在生产环境都必须显式填写；零会阻止相应请求或模型调用。应用的宿主机端口仅绑定 `127.0.0.1`，只信任由受控反向代理写入的 `X-Real-IP`，代理将原始客户端该标头覆盖。网页身份由同源、HttpOnly、SameSite Cookie 绑定；小程序使用 `/api/flow/session` 签发的短期 Bearer。原文和本地注脚不进入公开资源桶。
