# 点词原文补召回离线试验

本批保留现有生产召回。严格条件在 18 轮中触发 0 次。放宽后有 4 轮进入本地试验，2 轮可以补入一个末位摘窗，预标证据组增减均为 0。放宽规则触发的 3 个已盲评读点中，2 个原摘窗已被判为可直接接续。试验使用第一批封存的 6 个读点和 18 次真实规划结果，本批未发模型请求。

## 触发及试验方法

1. 用生产摘窗的来源 ID、版本、哈希和 UTF-16 范围回到原文。按逗号和分号不截句、句末标点及原文换行截句。原句须完整落在该摘窗内，且经 `repeatsQuotation` 判为未读。以 `quotationKey` 规范化后，检查是否完整包含本轮未回抄的规划短语。诗词只在送模片段可核对的原句边界内计数。
2. 严格条件要求本轮至少有两个不同的回抄短语，且 Top12 未覆盖任何合格的未回抄短语。18 轮里有 10 轮达到回抄阈值，18 轮均有至少一个未回抄短语得到完整未读原句支持。
3. 因严格条件未触发，仅诊断放宽条件。达到相同回抄阈值、Top12 只覆盖至多一个不同的未回抄短语且仍有缺席短语，才进入窄检索。扫描 11,722 篇本地典籍，诗词启用时另外用本地 `searchPoetry` 检索一次，限返回 32 篇。诗词列的分母是这次检索实际返回的篇数。
4. 保留来源范围和原排除项，补入来源须未出现在原 Top12。候选须含本轮原有的缺席短语，且用现有 `compactCandidates` 取得摘窗后仍能核对完整未读原句。候选按缺席短语原序、是否已在原 Top40、来源 ID 排序。保留原前 11 段。只试图补一段到末位，末位已有合格原句就保留。选定后才用冻结预标证据打分。

放宽条件在诊断轮触发 0／6，在留出轮触发 4／12。四次试验共有五个预标证据组机会，Top12 命中均为 1／5，按轮命中均为 1／4。这里以四次进入补召回试验的轮次为分母。

「乐之者」补入的是「君子无入而不自得焉」。原第一轮摘窗已有《荀子》说明反复实践如何养成喜爱，并有《孟子》「反身而诚，乐莫大焉」。同一窄检索还检出《尚书》「凡民自得罪」，显示「自得」逐字匹配会混入另一用法。「时习」补入的是「博学之，审问之，慎思之，明辨之，笃行之」，原窗已有「温故而知新」及「道问学」。两次模拟均保留了第一批盲评列出的原窗直接证据。

三次放宽触发有对应的首轮盲评。「乐之者」和「时习」原摘窗为 D，「孰乐」为 P。由此，放宽条件在这三个已复核样本中有 2 个误报。其余一轮没有首轮盲评结论；补入摘窗也没有经过新的生成或交付盲评。当前证据不满足上线门槛。

## 复跑

在仓库根目录使用封存的上下文、规划记录和已归档摘窗盲评。命令把中间结果写入新临时目录。

```sh
run_dir=$(mktemp -d)
archive=docs/qa/flow-blind/2026-11-25-plan-stability
TSX_DISABLE_CACHE=1 node --import tsx scripts/run-flow-plan-stability.ts \
  "${archive}-contexts.json" "${archive}-plans.json" > "$run_dir/stability.json"
audit=docs/qa/flow-blind/2026-11-25-local-evidence.cjs
TSX_DISABLE_CACHE=1 node --import tsx "$audit" \
  "$run_dir/stability.json" "${archive}-contexts.json" "${archive}-review.json" > "$run_dir/local-evidence.json"
shasum -a 256 "$audit" "$run_dir/local-evidence.json"
```
