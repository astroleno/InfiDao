# 点词阅读可读性验收

以 `e3e0b28` 为对照，用相同的原文「其恕乎！己所不欲，勿施于人。」、长释义、回响和屏外接续在本地阅读器验证。原文来自仓库语料。用固定服务响应检查界面行为，模型调用次数为零。浏览器保留水膜渲染，另验证减少动态效果和原生文字回退。

| 场景 | 实际结果 |
| --- | --- |
| WebKit 390 × 844 | 回响从 250 像素宽的居中栏放宽到 350 像素并左齐。经句仍为 250 像素。长释义完整可见，正文左右各留约 19 像素。 |
| WebKit 320 × 650 | 回响和释义正文分别宽 280、282 像素，行首稳定且没有横向溢出。 |
| 屏外到达 | 390 像素样例中画布和阅读视口止于纵坐标 780，「去读」从 786 开始。停靠前后的滚动位置一致，按下「去读」才滚动并聚焦新句。 |
| 点词往返 | 实际点击提交的原文身份与 UTF-16 词位正确。关闭释义返回原条目焦点，取消后迟到响应不会加进新句，浏览器返回恢复原条目。 |
| 渲染回退 | WebKit 系统减少动态和 Chromium 强制原生文字模式均通过相同的交互路径。 |

WebKit 的 390 和 320 像素视口、Chromium 的 390 像素视口、WebKit 的 1280 × 720 桌面视口以及两种回退设置，共六种配置完成浏览器验证，均无页面错误。390 像素停驻截图中，原文和加宽的回响行完整可见，等待提示和停靠后的「去读」都有各自可辨认的位置。此前 WebKit 的长释义可以把弹层撑出屏幕，现已用有宽度约束的网格轨道定位。手机停驻时，折光区收至每边不超过屏幕高度的 12% 和 82 像素；滚动恢复原有折光强度。绘制和触点还原共用同一帧参数。

单元回归另外覆盖等待超过 12 秒、原句已放行后的补全状态、提示停靠缩短视口时的到达边界，以及滚动前后逆投影。等待状态保留本次点中的词和停止入口。首次接续继续使用独立核验后的流式放行。

用户已确认以本地 WebKit 验证推送本批。iPhone Safari 真机仍待验，尤其是浏览器栏与安全区变化时的触摸和停靠位置。
