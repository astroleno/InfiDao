# 横屏补充与 DeepSeek 内容实测

## 已复现的问题

公网原版本 `infidao-e40edebd06ab0a53` 已有经轮横屏字号和字距适配，但面板适配不完整。Chromium 的 844 × 240 视口中，输入面板高 282.5px、顶部为 -58.5px，标题被裁切。不能用经轮长句不重叠的测试代替完整横屏验收。

## 修复与本地验证

- 输入面板限制在可见高度内，内容溢出时可滚动；保留横屏刘海、安全区域边距。
- 监听 VisualViewport 的 resize/scroll，让输入和注脚所在的 DOM 面板避开键盘；打开键盘不改变经轮画布尺寸。缩放时保留浏览器的平移和缩放行为。
- 低屏高下压缩静读标题间距和引文字号，正文用 flex 可收缩滚动区，底部控件不再被父容器裁切。
- 文本输入字号为 16px，避免 iOS 小字号输入触发自动放大。
- 14 项相关 Jest 测试通过；`npm run type-check`、`npm run lint` 通过。原本缺少本地依赖，先按现有锁文件恢复依赖，没有更新版本。
- 实际浏览器检查 844 × 390、390 × 844、844 × 240、1280 × 720 连续切换，等待 viewport 事件完成后检查：无横向溢出；阅读层均位于视口内；正文可滚到最底部。
- 844 × 240 输入面板修复后顶部 12px、高 216px，滚动 23px 后两个按钮完全可见。
- 合成键盘测试将 VisualViewport 改为高度 180px、顶部偏移 36px，两个操作按钮均落在可见区域内。此项只验证事件与布局逻辑，不能代表 iPhone 系统键盘。

截图保存在 `output/qa-2026-09-30/landscape/`。实际 iPhone Safari、微信内置浏览器的旋转、地址栏和键盘测试仍未通过真机验收。

## DeepSeek 实测

请求直接经过 `https://aitoshuu.me/api/flow`，使用同一个匿名会话，未绕过服务端预算。服务器模型配置为 `deepseek-flash`，官方 API；没有读取或输出模型密钥。原始合成样本响应保存在 `output/qa-2026-09-30/deepseek-seeded-results.json`。

| 输入 | 实际结果 | 时间 |
| --- | --- | --- |
| 想睡觉 | 《论语·乡党》“食不语，寝不言。”，返回完整释义、联系和两个锚点 | 首个 frame 与 done 均约 9.576 秒 |
| 同事把功劳揽到自己身上，我很生气 | `BUDGET_REACHED`，没有生成可评价的结果 | 约 5.101 秒 |

成功样本的“原文之义”为：吃饭时不交谈，睡觉时不言语，是孔子日常居处恭敬慎重的表现。

“与你此刻的联系”为：睡前少言，让心思从白日的应对中慢慢收拢，或可看作一种安顿休息的仪式。

评价：引文确实存在于响应中的完整原文，quoteStart/quoteEnd 截取一致，来源定位有效；主题和“睡觉”相关，释义与现代联想分开呈现。但回应主要沿“寝”的字面关联，没有充分回应疲惫等潜在处境，不能据此确认复杂输入的效果。单样本也不能代表稳定性。带 seed 的这次请求没有提前 head，用户约 9.6 秒才收到首段内容，先前空白开场约 1 秒的固定《大学》首句不能套用到此场景。

当前预算：全站 20、访客 5、IP 10 次实际模型调用／UTC 日。两次输入合计用了该会话的 5 次模型调用，第二次在流程中途被阻止；最终全站计数 7、活跃请求 0。规划、校验修复、释义都计费，因此“5 次模型调用”并不等于“可以输入 5 个问题”。没有提高限额、重置计数或更换身份继续测试。后续需要在用户确认的额度内补测复杂处境与分叉。

## 发布

- 公网预览已切换至 `infidao-c3f5393613ce1a8f`，源包 SHA-256 为 `43421b223fd23226b3ab20229aba3b3ec658a7d2d6f020b210a55bb9de04fa79`。900MiB 上限构建成功，组装校验 2 个语料文件、13 个字体分片与 10 个顶层 JS chunk；独立 canary 的健康接口和 12 个页面静态资源均通过后才切换。
- 首次公网检查发现宝塔在 HTTP 全局启用了 `proxy_cache cache_one`，使普通 `/infidao` 仍返回旧 HTML。单看发布清单与静态 HTTP 200 不足以识别此问题。已对 `/infidao` 和子路径显式关闭代理缓存并隐藏上游的长期缓存头。普通入口现在返回新版本 CSS，缓存头为单个 `no-cache`。
- `/_next/static/` 使用单个 `public, max-age=31536000, immutable`，修复先前叠加 `no-cache` 导致重复校验的问题。保留上一版哈希静态资源，防止切换期间旧页面请求缺失。
- 修正缓存后，重新校验公网 12 个实际页面资源、发布清单、首页及 `/lubirth/`，均通过。公网浏览器确认输入面板顶部 12px、高 216px，按钮可滚动到完全可见，页面无横向溢出。截图为同目录下的 `public-landscape-short.png` 与 `public-landscape-reading.png`。
- 上一应用 `/opt/infidao-releases/infidao-e40edebd06ab0a53` 保留，Nginx 片段备份为新发布目录中的 `nginx-before-landscape.inc`；校验服务已停止。模型额度、会话存储与语料没有更改。应用/Redis/Nginx 均 active，Docker service/socket 仍 inactive。
