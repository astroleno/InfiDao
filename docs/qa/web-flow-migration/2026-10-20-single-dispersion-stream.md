# 单一色散经文流验收

## 交付范围

- 本地 `/infidao`，release `b68d50a8adae67de`；未提交、推送或发布公网。
- 一个持久挂载的阅读容器：经文、释义、此刻的联系、点词等待与续读都在其中。停驻仅改变移动状态。
- 真实可点文字本身接受曲率、景深和光谱分离；焦点保持白色，控件为白灰。没有第二个背景经轮或停驻抽屉，没有金色装饰。
- 可见前文保留所属服务端链与本机路径。选择旧段落中的词直接沿其语境生成，不先切换界面。
- 收藏状态逐经句显示；注脚按实际所属链保存，切换段落时清除前一段的显示缓存。
- 滚动接近尾部才预备一段，继续阅读接管同一个请求；停驻中的 Tab 导航和布局变化不会自行消费续读。

## 真实流程

复用 Ego Lite 的 `infidao-live-reading-20261020` 验收页及现有本地服务，调用真实 DeepSeek `deepseek-flash`，未使用模拟生成。思考关闭和上下文策略沿用既有配置。

1. 输入「总是在同时做很多事，怎么分清本末与先后？」。
2. 首段经文和完整释义到达、联系仍在生成时，先点释义中的「万物」，约 57 ms 后改点「根本」。两个点击发生时界面均为生成中。只有最后一次选择发起分支请求；原生成已停止。
3. 新经文接入后，原文章节点、原选词按钮、滚动容器均保持相同 DOM 身份；键盘焦点保留，滚动位置前后均为 7 px。
4. 再点前文原句中的「先后」，正确从其原服务端链生成另一方向。前文节点及容器保持，滚动仍为 7 px。
5. 向下阅读两次：各接管一次实际预备请求，形成四段可回看的连续内容。没有重复请求、跳回顶部或替换前文。
6. 重新载入后四段与保存位置恢复，新增 API 请求为 0。重访前文「先后」已有连接，新增请求也为 0。
7. 开始流动、移动 4 px 后停驻，文字按钮与容器身份均未变化。页面只有一个连续经文流，Canvas 数量为 0。

首段在转向时仅保留已核验的经文和完整释义；尚未完成的联系没有伪造补全。当前方向及后续两段均完成独立核验。
