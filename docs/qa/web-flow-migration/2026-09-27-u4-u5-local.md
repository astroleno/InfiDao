## 费用回归

最终生产浏览器联调曾触发请求上限。检查共享 Redis 计数后确认：静读停驻时，首帧被误当成流动边缘，页面自动生成了两条后续经句，消耗了模型日额。已将预取限定为画面流动的首帧或用户主动移动到边缘，`tests/unit/flow-browser-interaction.test.ts` 覆盖停驻、减少动态效果、流动和移动四种情况。更新后的生产构建在独立命名空间实测静读 6 秒没有后续请求；主动点词才生成子链。

## 验收界限

本地独立构建已复制只读语料与字体并启动；本机无 Docker、目标 COS/CDN、HTTPS 网关和实际 iPhone／微信环境。因而镜像运行、目标 CDN 跨域与缓存、真实网关的逐事件转发、手机触摸和公网回滚均尚未通过。当前没有公网部署或首页替换。
