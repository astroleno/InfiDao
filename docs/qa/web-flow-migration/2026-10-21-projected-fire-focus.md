# 火光按字形投影距离聚焦

日期：2026-10-21。对应计划 016。用户明确近处指「靠近字形的投影光斑」，希望近处清楚、远处模糊。

后续用户指出该版中央彩色字形过于抢眼，要求恢复白字主导、彩光在字侧后方的主次。当前调整与知识关联验收见 `2026-10-21-knowledge-and-quiet-fire.md`；本文保留为该次聚焦调整的历史记录，不代表用户认可其最终视觉。

## 实现

- 在玻璃片元中计算未扰动折射射线的画面投影偏移；从约 3px 到 36px 或当前行距的 1.1 倍，连续增加采样发散。
- 连续流的法线粗糙度从近处 0.003 逐渐增至远处 0.10，替代只跟随玻璃景深的统一模糊。近处的采样相位稳定在各波长区间中点，减少笔画附近随机抖散；远处仍保留原有采样分布。
- 远处光线逐渐减弱至 58%，让散开的光更柔和。完整波长区间、八组采样、前后两次透射及一次 Bend 保留，没有增加贴图、光栅或绘制通道。
- 折射源去掉预先模糊，折射缓冲比例从 0.5 调至 0.75，以保留近处彩光细节。文字前景的景深仍独立处理。
- 原经轮的连续流开关为零时，使用原粗糙度、相位与亮度。正文布局、逐字显影、点词及阅读图谱接口未修改。
- 同步既有测试中光源滤镜及缓冲比例的期望，没有新增或执行测试。
