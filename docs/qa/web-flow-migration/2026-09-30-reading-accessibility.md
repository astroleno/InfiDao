# 2026-09-30 阅读与键盘迭代

## 范围与实现

用户在逐项讨论界面审阅意见后要求继续迭代，并明确要求 commit、push。本轮沿用网页经轮架构和原文位置接口，不重建字体或修改原文分词规则。

- 辅助文字使用固定浅色，出处、段落标签与路径提升到 12px；统一按钮、文本框的 2px 焦点轮廓。阅读覆盖区改为不透明深色，避免轮盘字影穿过正文，覆盖区外保留经轮。
- 经文显示把开引号与后词、句末标点与前词放在同一个不换行组中。按钮仍使用原来的字词与 UTF-16 位置、原文哈希和语料版本。
- 每段选词只保留一个 Tab 停靠点；左右键切换词，Home/End 到首尾，回车沿当前词接续，Tab 离开。保留原生按钮语义，并给出文字操作提示。
- 经轮聚焦后上下键停驻并浏览前后行；沿用共享时间轴和行窗口，经过窗口边界仍可反向操作。空格继续控制停驻。
- 输入面板打开时，沿其父节点逐层隔离背景兄弟节点，设置 inert 与 aria-hidden，关闭恢复原属性和入口焦点。移除会抢先覆盖入口焦点的 autoFocus，由已有聚焦逻辑接管。
- 删除注脚后焦点移至相邻注脚，全部删除后移至撤销；恢复后回到输入框，并以 status 通知结果。异步失败保留可重试提示。
- 品牌改为 h1，界面用词统一为“来路”。不增加整屏模糊和非必要退出动效。

## 验证

- 相关 Jest 23 个测试文件、115 项测试通过，覆盖原文选词参数保持不变、标点分组、键盘选词、删除/撤销焦点、弹窗隔离与恢复、经轮窗口边界和图形上下文丢失。
- TypeScript 应用与脚本检查、ESLint 均通过；小程序 124 项回归通过。
- 本地 Chromium 检查：经文仅一个 Tab 停靠点；ArrowRight 移动焦点，Tab 到释义入口；实际焦点轮廓为 2px。输入面板打开后背景 inert，Escape 后焦点回到“一念”入口且 inert 清除。
- 320×740 窄屏及 844×390 横屏均无文档横向溢出，带标点的词组保持一个行盒；出处和段落标签实际为 12px。横屏经轮上下键操作后保持停驻，焦点仍在 canvas。
- 浏览器验收拦截内容生成请求，使用已有经文验证布局与操作，不据此声称 DeepSeek 质量有提升。
- 本轮未做 iPhone Safari、微信内置浏览器或 VoiceOver 真机验证，不能声称完整无障碍合规。
