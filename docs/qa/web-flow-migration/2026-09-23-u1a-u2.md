# Web Flow Migration: U1a / U2 QA

Date: 2026-09-23
Status: U1a passed; U2 visual route passed locally; required iPhone Safari and WeChat WebView checks remain open.

## Verified

- `/infidao` renders the full-screen WebGL wheel in a production standalone build.
- Chromium desktop viewport: 1280 × 720. Responsive viewport: 390 × 844. These are desktop browser viewports, not real-device emulation.
- Pausing opens the reading layer; linked words create an opaque local history path; returning restores the parent path.
- Switching the browser preference to reduced motion pauses the wheel. The reader can still choose to resume it.
- The production page emitted no browser console errors during the pause, local branch, return, or reduced-motion checks.
- The wheel renderer caps backing pixels at 2.5 million. Shared/native runtime parity includes even and odd slot loops, long drag continuity, UTF-16 word ranges, and out-of-view content insertion.
