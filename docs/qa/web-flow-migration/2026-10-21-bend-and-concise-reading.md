# 上下 Bend 与按需短释义核对

范围：本地 `http://127.0.0.1:3165/infidao`，同一 Ego 空间 12、同一阅读访客。未提交、推送或发布。现有保存段落没有改写，因此界面截图中的解释仍是原有阅读记录。

## 已实现

- 采用 tongye-gallery 的圆弧折弯公式、40 段逆投影和连续上下折弯参数。整面倾斜与翻转关闭，中间保持平直。
- 原玻璃材质及两次透射保留，边缘前景字与色散合成后统一 Bend。中央原 DOM 字保持清晰；边缘的原按钮和语义仍在，指针坐标按同一投影还原。
- 原有左右入场和单一滚动容器保留。控件、输入和键盘继续使用原生 DOM。
- 新提示版本 `connected-text-v11`：难句一两句必要白话，易懂句 `meaning=""`，随后自然进入当前一念的联系。生成与独立关系核验的调用数不增加。
- 空释义也能 settled，联系可以在最终生成结束前显示、点词；省略释义时不产生空段落，联系从经文对侧入场。
