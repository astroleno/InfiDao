## 切换前发现并修复的问题

### 旧阅读位置被当成全局流偏移

旧版保存的 `reader: 570.5` 属于原链内部。新版同时挂载祖先链后，该偏移会落到更早的经句。现在根据保存的经句和路径校验偏移是否仍指向该经句；不匹配时把该经句放回阅读区，仍有效的全局偏移原样保留。原文导航继续单独定位准确引文。

新增回归先失败，再完成补修。真实公网浏览器保留原六条路径和原快照验证，保存的《康诰》经句在 320、390、1440 像素下均回到清晰区，没有生成请求。尺寸设置、页面加载与截图放在同一浏览器操作轮次内，避免工具退出时还原临时尺寸造成测量偏移。

### 温故在窗口变化时丢失所选主题

背景阅读区因视口变化更新当前经句，曾使已经打开的关联页重新加载上下文，丢失正在浏览的主题。温故现在保留打开时的阅读上下文。新增回归先失败、补修后通过；最终公网候选在三种宽度间切换，始终保留「明德慎罚」主题和直接关联。
