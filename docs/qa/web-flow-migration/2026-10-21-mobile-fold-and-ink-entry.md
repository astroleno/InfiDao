# 手机折弯与字迹浸染验收

## 范围与来源

按已确认的 `2026-10-21-010-feat-mobile-fold-and-ink-entry.md` 实现。本地参考为 `TongyeGuanmi/app/src/production/loader-ink-reveal.ts`、`loader-ink-sequence.ts`、`StoryLoader.tsx`；另在其真实 Vite 页面调用原控制器观察 260/390/650ms 的字形遮罩与湿墨边缘。参考项目源码未修改。

InfiDao 继续使用自己的字库、白字、原钻石玻璃与左右入场。新增逐字进度纹理进入现有文字合成流程，没有新增可见画布、WebGL 上下文或光学渲染通道。

## 手机折弯

旧 400px 焦距使近处的透视放大抵消纵向压缩。手机现用 1400px，600–900px 视口宽度间平滑过渡，桌面保持 400px。以下是 390×844 中相同源文字位置的局部缩放：

| 源文字距顶部 | 旧横向 | 旧纵向 | 新横向 | 新纵向 | 新纵横比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 10% | 1.678 | 2.375 | 1.131 | 0.637 | 0.564 |
| 20% | 1.288 | 1.550 | 1.068 | 0.831 | 0.778 |
| 30% | 1.097 | 1.192 | 1.026 | 0.945 | 0.921 |
| 40% | 1.009 | 1.039 | 1.002 | 0.996 | 0.994 |

上下对称；中央清晰，向边缘逐步压缩字高和行距，保留已有模糊与色散。圆弧、平滑连接和逆向命中采用同一参数。最外侧源坐标 0/height 的浮点误差已处理。

## 字迹显现

- 每字 650ms，段内交错最多 180ms。多尺度噪声在真实笔画内逐渐显露，短暂湿边随后收束至完整字形。
- 原生按钮、焦点和段落身份持续保留。中央字在浸染期间使用同一前景画布，完成后恢复原生字形；折弯区域继续走原光学画布。
- 段落按 Unicode 码点保留共同前缀进度，追加只启动新字。滚回、分词包装变化、字体变化和窗口重测均不重播已有进度。
- 新增对已安装字体列表变化的观察；已加载 FontFace 加入字体集不一定触发 `loadingdone`，因此显式重测画布字形，修正观察到的画布与正文短暂字体不一致。
- 暂停保持最后绘制的像素；恢复接着显现。键盘聚焦立即完整显示所在段。减少动画立即完成并保持原生清晰文字；图形失效时原生文字恢复，图形恢复后仍是同一按钮。

## 浏览器检查

使用 Ego Chromium、本地页面已保存的 4 段真实内容。模型额度设为 0；所有捕获和交互均记录 API 调用数 0。手机检查为浏览器尺寸和触摸模拟，本轮未连接真实 iOS/Safari 设备。

| 视口 | 光学状态 | 横向溢出 | WebGL 错误 | API 调用 |
| --- | --- | ---: | ---: | ---: |
| 390×844 | ready | 0 | 0 | 0 |
| 320×740 | ready | 0 | 0 | 0 |
| 844×390 | ready | 0 | 0 | 0 |
| 1440×900 | ready | 0 | 0 | 0 |

- 350ms 触摸空白处暂停：3 个正在显现的段落被冻结，推进动画时钟后画布 SHA-256 完全相同；继续流动后像素继续变化。
- 浸染中用触摸点击折弯后的「先」，准确激活同一原生按钮一次，所属经文正确；聚焦立即完整显示该段。为保持零调用，验收在按钮上截获点击，未触发新内容生成。
- 右方向键保留同段原生选词导航；真实触摸拖动可滚动；返回已读段不重播。
- 减少动画时无浸染属性、无位移，文字完整显示；恢复普通模式后不重播。
- 实际触发 `WEBGL_lose_context`：原生文字恢复至自己的不透明度；恢复后按钮身份不变，WebGL 错误 0。
- 起始/中间/结束帧使用受控动画时间戳捕获真实页面，未改文本或着色器。每 50ms 一帧组成预览，完整显现后保留静止结尾。
