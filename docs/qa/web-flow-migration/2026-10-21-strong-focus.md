# 加强上下弯曲与失焦层级

用户指出上一轮层级仍不明显，要求上下更模糊、更弯曲。本轮沿用“中央较远且清晰、上下更近且失焦”的凹面方向，直接加强几何和失焦幅度。

## 修改与同位置对照

| 项目 | 上一版 | 本轮 |
| --- | --- | --- |
| 最大弯曲角 | 72° | 86° |
| 弧面达到最大角度的位置 | 折弯区的 86% | 折弯区的 58%，邻近行更早弯曲 |
| 焦距 | 760px | 540px，近处放大更明显 |
| 上下折弯区 | 各 32% 视高，最多 280px | 各 38% 视高，最多 360px |
| 中央完全平直区域 | 至少 36% | 至少 24% |
| 模糊上限 | 桌面 2.2px、手机 3.2px | 桌面 7px、手机 9px，并提前进入明显失焦 |

以 390×844、源坐标 y=200px 为例，正文模糊由约 0.215px 增至 4.807px；x=90px 的显示位置由约 88.15px 改为 78.26px，朝外展开约为之前的六倍。该例用于说明幅度；视觉结论来自下面的实际页面对照。

- 手机前后均为 390×844、滚动位置 1041px；桌面前后均为 1440×900、滚动位置 1009px。使用同一组四段保存内容，没有替换文字或加工截图。
- 手机实看：上方两行由近乎清晰改为明显失焦，中间几行保持锐利，下方文字更快进入模糊层。释义滚入中央后恢复清晰。
- 桌面实看：上下几行的放大、弯曲和失焦更明显，中心字形清晰。钻石玻璃材质和多波长色散继续使用，没有换成描边或另一套材质。
- 还查看 320×740、768×1024、844×390；窄屏和横屏中央仍有清晰阅读行，上下呈现更强的弧面和失焦。

实际改动为共享 Bend 参数、`ribbon-optics.ts` 清晰度曲线及相关回归；原玻璃着色器、正文/色散合成流程和原生词按钮保持原有设计。

## 验证结果

- 6 组 45 项回归通过；应用/脚本类型检查、修改 TypeScript 文件的定向 ESLint、差异空白检查通过。
- 五种视口均为光学层 ready、WebGL 错误 0、无横向溢出，保留同一滚动容器、首个词按钮和四段内容。直接读取实际着色器 uniform，确认运行的是 86°、540px 参数。
- 桌面鼠标和手机模拟原生触摸，分别在上下 16%、29%、71%、84% 区域检查，共 8 次正确命中原词与 frame。转发事件在生成处理前截获，只核对输入映射。
- 更强弯曲的命中示例：手机上沿“古”源位置 `(63, 134.80)` → 显示 `(27.21, 136.12)`；桌面上沿“古”约 `(432.73, 144.08)` → `(348.45, 139.84)`，均命中正确。
- 手机实际触摸滚动从 431px 到 576px，同一“可先”词的模糊从 2.8px 变为 0，保持同一节点和停驻状态。
- 减少动画时全部原生文字清晰、折弯标记 0；图形丢失时画布隐藏、原字可见，恢复后 ready、WebGL 错误 0、节点与内容保留。
- 本轮浏览器操作的 `/api/flow` 请求数均为 0；本地模型额度设为 0，未新增模型调用或修改既有预算。

检查过程说明：首次启动时服务尚未就绪，随后开发编译较慢，出现连接/载入等待超时；在同一 Ego 空间 23 等待实际加载完成后继续。第一次横屏采样要求整行框落入中央 40%–60% 范围，因行框上沿约 154.48px 比阈值 156px 略高而没有样本；实际行中心约 188.82px，字无模糊、透明度 1。采样改为按字行中心位置后完成五种尺寸确认，未为此修改界面或跳过检查。
