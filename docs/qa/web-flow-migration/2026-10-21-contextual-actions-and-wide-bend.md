# 按需操作与多行 Bend：实现和一轮评审

状态：本轮 UI 范围已在本地验收，未提交、推送或发布。

## 修改

- 原文、收藏、注脚收进同一操作入口。桌面随段落悬停/键盘聚焦显露入口，触屏保留小省略号，实际点击区为 44×44px。点词仍直接接续。
- 菜单沿用原有数据与动作回调，支持 Tab、Escape、外部点击、滚动/尺寸变化关闭。动作执行后焦点回到入口；收藏状态变更后短暂显示并播报结果。
- 上下折弯区由最多 150px、屏高 18%，扩大为最多 280px、屏高 32%；圆弧占该区 86%，角度仍为 72°。像素与点击还原使用同一设置。中央至少 36% 保持平直。

## taste / impeccable 评审

方法：主线程使用两套 Skill 的适用规则和真实浏览器截图依次检查，非独立 agent 评审。视觉约束为已确认的钻石色散、古典字形、连续阅读流。一次成组检查、一次修正、一次确认。

| 视角 | 观察与处理 |
| --- | --- |
| taste：构图与层级 | 常驻三连按钮已收起，主画面由经文和分光构成；桌面 40px、手机 30px 的经文保持清晰主次。上下多行共同进入圆弧，中央阅读区保持平直。未添加新的装饰内容。 |
| taste：手机画面 | 390px 和 320px 可连续阅读，省略号入口可见；宽折弯只作用于文字与光学层，操作菜单保持平直。 |
| impeccable：可发现性与操作 | 触屏保留明确的操作入口；每项按钮实际 52×44px，键盘能展开、Tab 进入动作、Escape 退出并返回入口。来源说明和注脚输入仍可到达。 |
| impeccable：发现的问题 | 初版菜单固定向上展开，在顶部会被顶栏渐隐遮罩压暗。已按实际顶栏位置选择向上/向下展开，滚动和改变尺寸时关闭。确认截图中菜单顶部约 124px、左右 111–279px，三项中心均正确命中。 |

机械检查的实际范围：

- Impeccable `detect --json` 扫描 `StreamActions.tsx` 和 `FlowStream.tsx` 返回 `[]`。
- Taste 源码扫描加入共享 `flow.module.css` 后报告 24 个 FAIL 模式命中、8 个 WARN。命中集中于共享 CSS：辅助画布/读屏元素的 1px 尺寸、既有阅读层与弹层样式、光学加载效果、顶栏遮罩，以及本次真实浮层的阴影。按本项目既有视觉约束和当前变更范围分类处理；未将这些模式计数冒充实际界面缺陷，也不声称整个共享 CSS 通过 Taste 的营销页规则。
- 渲染检查使用 Ego 同一任务空间的真实页面和 DOM 读数，未运行另开浏览器的 Taste inspector，未注入 Impeccable 可视化覆盖层。未将它们报告为已通过。
