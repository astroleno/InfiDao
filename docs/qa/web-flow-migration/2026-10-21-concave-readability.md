# 凹面阅读与手机可读性修正

## 已确认方向

用户批准保留两三行 Bend 和原钻石色散、手机优先清晰，并进一步明确“上下更近但是模糊”。本轮按**中间较远且清晰、上下靠近观察者并逐渐失焦**实现。此前将凹面解释为“上下退远”不准确；本轮没有反转 Bend 的深度符号。

## 实际修改

- `ribbon-optics.ts` 取消额外的边缘缩小。正文与色散合成后的 Bend 是唯一透视来源，避免向前弯曲又独立缩小的冲突。清晰度按同一折弯区计算，中央保持无模糊和完整亮度；越靠上下沿越模糊、越暗。窄屏的边缘失焦稍强。
- `stream-glass.ts` 让色散采样继承原文字的透明度和模糊，避免已淡出的字仍产生明亮、可辨读的残影。
- 原玻璃着色器新增仅连续阅读流启用的阅读带衰减，在最终玻璃光合成时降低残影；手机比桌面更弱。原前后两次透射、玻璃几何、多波长色散继续使用。正文前景不受该玻璃光衰减影响。
- 上下折弯范围仍为各 32% 视高、最多 280px；原 72° 弧面、逆投影、左右入场和同一组原生词按钮继续使用。未改生成、存储或额度接口。

## 实看结果

使用本地 `http://127.0.0.1:3165/infidao`、Ego 空间 17 和之前保存的四段真实内容，逐张查看页面截图，检查经文和释义滚入中央的两种状态。

| 视口 | 观察 |
| --- | --- |
| 手机 390×844 | 中央经文笔画清晰；释义进入中央后清晰可读；色散保持彩色玻璃残影，但亮度降低。上下几行靠近并逐渐失焦，不再有额外的缩小。 |
| 窄屏 320×740 | 中央行清晰，没有横向溢出；下沿文字进入模糊区，滚入中央后恢复清晰。 |

以上五种视口均保持同一滚动容器、同一首个词按钮和四段内容；光学层 ready，WebGL 错误为 0。中央采样词均为无模糊、透明度 1。颜色和可读性的判断来自实际查看截图，未用像素计数替代视觉检查。

## 交互与回归

- 6 组、43 项回归通过：Bend/逆投影、清晰度、色散输入、渲染通道、阅读流和左右入场。
- 应用与脚本类型检查、修改 TypeScript 文件的定向 ESLint、差异空白检查通过。
- 桌面鼠标点击和手机模拟原生触摸分别检查上下 16%、29%、71%、84% 位置，共 8 次正确命中原词和 frame。转发事件在生成处理前截获，只证明输入映射，没有冒充新分支生成。
- 示例：手机上沿“古”原坐标约 `(63, 134.80)` → 显示 `(54.23, 128.27)`，下沿“知”约 `(75, 709.05)` → `(67.05, 715.58)`，均命中正确。
- 手机模拟触摸滚动从 421px 前进到 566px，保持停驻状态和同一容器。
- 减少动画：折弯标记为 0，所有原生字无变换、无模糊、透明度 1。图形丢失时画布隐藏、原生字可见；恢复后 ready、WebGL 错误 0，词按钮与四段内容保留。
