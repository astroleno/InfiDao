# 经轮边缘与检索索引迭代

## 已确认范围

用户要求继续优化并消除网页左右两侧的框；随后明确同意复用 Redis 保存当前访客已核验的经文释义与概念，按语料版本隔离，设置容量与过期时间，不增加模型预算。

## 模块与接口

- 网页渲染适配开启无边缘亮带模式：玻璃掠射反光关闭、掠射透射平滑消隐；字形、中央色散和小程序默认效果保留。桌面阅读面板铺满宽度，以内部留白保持阅读行宽，移除左右边线。
- `buildLexicalIndex` 只为不可变语料建立二字相邻片段的倒排表；选出候选后仍调用原评分与排序规则。单字线索回退全量候选，短语仍做完整匹配。
- `candidatesFor` 的已有参数保留，新增可选的访客语义条目参数；HTTP 请求和响应格式不变。索引与 ID 映射每个进程构建一次，构建失败可重试。
- 会话文档增加可选 `semantics`，旧 schema 1 文档仍可读取。预留操作同时读出当前访客语义条目，完成事务同时写入，避免额外 Redis 往返。失败、取消及过期工作不写入条目。
- 每访客最多 256 条，每条最多 1,200 字符、6 小时有效；语料版本、原文哈希及提示词版本均需匹配。仅保存释义与核验后入口概念，不索引用户输入、个人短解或阅读角度。
- 此索引是随阅读积累的访客语义辅助召回，不等同于对全部语料完成语义建模，也不代表旧版向量索引已通过检索质量验收。

## 验收标准

- 桌面与手机横竖屏均无可见的经轮左右硬边，文字和色散保留；阅读面板无左右框线。
- 倒排候选与原全量词法检索的结果、分数和顺序一致；记录相同查询集的耗时与构建成本。
- 语义条目跨存储实例读取一致，隔离访客，拒绝过期/旧版本/旧文本条目，受容量限制；未成功提交的生成不写入。
- 延续既有会话、预算、渲染回归与类型/代码检查；模型预算保持原上限。

## 结果

- 本地类型检查与 lint 通过；22 个相关测试文件、110 项测试通过。小程序共享核心重新生成成功，11,722 条可用语料及资源分包仍满足原容量限制。
- 在 11,829 条原始语料上对 23 个查询逐一比较，新旧候选、分数和顺序一致。7 轮交替计时，整组全量扫描中位数 489.65 ms，倒排检索 40.03 ms；一次建表 226 ms。本次堆内存增量读数 53 MiB 含临时分配，不能解释成稳定驻留内存。数据见 `output/qa-2026-09-30/index-benchmark.json`。该结果仅代表本机 CPU 检索，不代表模型或端到端响应加速倍数。
- 种子规划与索引准备并行，首次建表可与模型规划等待重叠；后续复用进程索引。没有减少关系核验步骤，也没有增加调用额度。
- 目标服务器上的隔离 Redis（独立 Unix socket、临时目录，不连接正式 Redis）通过真实 AOF 重启后的语义条目恢复、访客隔离，以及原有并发、租约、完成重放和预算重启检查。
- 本地 Chromium 实景核对 1440×900、390×844、844×390；经轮两侧硬边消失，白字及色散保留，无文档横向溢出。桌面阅读层铺满宽度，左右 border 均为 0。截图见 `output/qa-2026-09-30/borders-after-fresh.png`、`borderless-reader-desktop-final.png`、`borderless-portrait.png`、`borderless-landscape.png`。这不代替 iPhone Safari／微信浏览器真机验收。
- 本地开发资源此前被 immutable 缓存命中，首次截图仍显示旧 shader；禁用浏览器缓存后，核对实际 shader 的 `u_borderless=1`，重新截图确认生效。发布须再检查公网哈希资源及页面版本。
- 冻结待发布版本 `infidao-219e8920dd17d801`；源码归档 SHA-256 `e256a2643758d60d24738acf739a684460af2924b076723bc646a8f1946a8d6a`。15 个 COS 对象已创建，CDN 全部 14 个字体对象通过哈希、类型、跨域和缓存检查；首次有一次网络读取失败，整组重试通过。

- 目标服务器受限构建成功退出；canary 的健康、版本清单、12 个页面资源及无边缘 shader 均通过后，原子切换 `/opt/infidao-current` 至 `infidao-219e8920dd17d801`，旧版本 `infidao-0f1b26d1d65a7ad4` 和旧静态资源保留，canary 停止。应用 active、自动重启次数 0。
- 公网普通 `/infidao` 返回新版本，HTML `Cache-Control: no-cache`，12 个页面引用资源均 200 且单个 immutable 缓存头；原首页与 `/lubirth/` 仍 200。记录见 `output/qa-2026-09-30/index-border-public-release.json`。
- 公网 Chromium 使用正常浏览器缓存，实际 shader 的 `u_borderless=1`，1440×900 桌面截图已确认硬边消失；390×844、844×390 无横向溢出。桌面阅读层左右边线均 0。截图为 `output/qa-2026-09-30/borderless-public-{desktop,portrait,landscape,reader}.png`。浏览器视觉核对拦截内容请求，未以模型生成内容作为本轮质量验收。
- 仍未完成实际 iPhone Safari／微信浏览器真机验收。该版本没有宣称提高模型语义判断的独立评测分数，也没有将本地检索计时等同于完整请求延迟。
