# 手机中央行宽与原玻璃色散修正

> 后续反馈：用户明确指出本版色散呈现纯色块、偏离原版钻石火光，色散增强由计划 015 修正。下文为本版历史检查记录，不能作为当前视觉效果已获认可的依据；列宽也已由计划 013 收窄至 64%。

日期：2026-10-21。依据用户本轮纠正：上一版光栅效果不足，希望加强原有色散；手机中央过宽，未形成上下宽度变化。范围见计划 012。

## 修改

- 正文列使用 72% 宽度，上限 692px，移除原来的水平 padding。390px 手机原文字区为 342px，本次为 280.80px；经文字号仍为 30px。1440px 桌面正文宽度保持 692px。
- 保留手机 1400px 焦距与纵向连续圆弧，增加随曲面深度平滑变化的横向展开。参数 `flare` 在手机为 0.5，600–900px 屏宽间平滑回落，桌面为 0。正向位置、逆向点词与最终 Bend 着色器使用相同公式。
- 撤下上一版独立光栅贡献。原玻璃透射继续使用八组 RGB 折射采样，在外围增加波长分离，适当收拢粗糙采样，并提升已折射颜色中扣除共同白光后的分量。保留两次玻璃透射与一次 Bend，没有增加绘制通道或额外纹理采样。
- 中央不启用本次色散增强；继续使用原字体、逐字浸染、原生按钮和导航。动画文字与色散读取同一份显影后的源图。

## 交互检查

- 桌面、390px 手机、320px 窄屏各检查 6 个纵向位置，共 18 次真实鼠标或触摸输入；全部只命中期望的原生按钮一次，frame 与焦点正确。检查拦截按钮业务事件，避免消耗模型调用。
- 在显影进行到 350ms 时触摸空白处，3 段显影暂停；推进受控时钟至 900ms，画布 SHA-256 不变；继续流动后像素变化。
- 显影过程中触摸投影位置的“治”，只激活同一原生按钮一次，聚焦后完整显字；右箭头可移到同段下一按钮。
- 减少动画时无显影标记，原生文字 opacity=1、transform=none；切回不重播。
- 触发实际 WebGL 上下文丢失时，原生文字恢复可见；上下文恢复后按钮不替换，图形错误为 0。
- 原生触摸拖动可滚动，回访已读内容不重播显影。以上交互新增模型调用为 0。
