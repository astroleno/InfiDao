# 连续弧面与更明显的 Bend

用户要求“更连续、更 bend”。本轮延续已确认的凹面方向：中央较远，上下更近并失焦；原钻石色散和正文共用最终投影。

## 调整

| 项目 | 上一版 | 本轮 |
| --- | --- | --- |
| 上下弯曲区域 | 各 38% 视高，最多 360px | 各 46%，最多 480px |
| 中央完全平直区域 | 至少 24% | 至少 8% |
| 曲线 | 前 58% 圆弧，后段直线延伸 | 完整圆弧，入口用五次平滑函数衔接 |
| 弯曲角 / 焦距 | 86° / 540px | 88° / 400px |
| 中央清晰范围 | 至少 24% | 保持至少 24%，独立于几何弯曲范围 |

`stream-bend.js` 的正向投影、逆投影和着色器同步调整；平直面到圆弧的入口保持位置、切线与曲率连续，外沿不再切换为直线。`ribbon-optics.ts` 单独保留原来的清晰度范围，因此中央邻近几行可以轻微弯曲且清晰，手机上下仍按原来的梯度失焦。原玻璃材质、两次透射、色散和输入接口保持已有设计。

以手机源位置 `(90, 200)` 为例，上一版显示 x≈78.26px，本轮 x≈68.91px，向外展开从约 11.74px 增至 21.09px。该数值用于核对变化，视觉结论来自实际页面截图。

## 实际页面检查

- 手机 390×844 和桌面 1440×900：前后使用相同四段保存内容、相同尺寸、相同滚动位置（分别 1041px、1009px）。没有替换内容或加工截图。
- 已逐张查看手机、桌面、320×740 窄屏、768×1024 平板、844×390 横屏，以及手机/桌面的释义阅读截图。正文邻近行开始轻微弯曲，上下近处放大和弧面延续更明显；中央经文与释义保持清晰，仍可看到钻石色散。
- 五种尺寸均 ready、WebGL 错误 0、无横向溢出；中央采样全部无模糊、透明度 1，保留同一滚动容器、首个词按钮和四段内容。实际着色器参数均为 88°、400px。
- 桌面鼠标和手机模拟原生触摸，分别在 16%、29%、40%、60%、71%、84% 位置核对，共 12 次命中正确。40%/60% 覆盖本轮新增的中央邻近弯曲区域；转发事件在生成处理前截获，不触发接续生成。
- 手机原生触摸滚动：同一“可先”节点保持连接，滚动从 429.5px 到 574.5px，模糊从 2.882px 到 0，保持停驻。没有内容替换。
- 减少动画时所有原字清晰、折弯标记 0；图形丢失时画布隐藏且原字可见，恢复后 ready、WebGL 错误 0、节点和内容保留。
- 本轮浏览器 `/api/flow` 请求为 0，预览模型调用上限为 0，未增加模型调用。

6 组 52 项回归通过，包含接合处位置/切线/曲率连续、五种尺寸每 2px 采样的单调投影与逆映射误差、清晰范围独立于弯曲范围。应用与脚本类型检查、四个修改 TypeScript 文件的 ESLint、差异空白检查通过。
