# 水膜动效候选模式验证

日期：2026-10-23。范围：将已确认的 `liquid-live` 动效接入正式阅读器，保留入场、逐字显现和画质，处理宽屏快滚掉帧，修复两项失败测试。保持默认关闭，未提交、推送或部署。

## 使用与行为

- 候选入口：`/infidao?motion=liquid`。菜单中可开关「水膜动效」。
- `motion=current` 使用原模式，并保留候选开关；没有这两个明确参数时，使用原模式且不显示开关。
- 开关只替换当前 URL 参数，不新增历史、不重新挂载阅读区、不保存全局偏好。分支与返回继续携带相应历史项中的模式。
- 正式阅读器保留入场与逐字显现。只有动效对照页显式请求跳过入场，以便比较静态样例。

## 实现

1. **按行合并模糊绘制。** 相同位置、相同模糊半径的一行先以原字体、字距、透明度和坐标绘制，再统一应用原模糊。缓冲原点对齐整数物理像素，最多复用 64 个行缓冲；尺寸变化、上下文丢失和销毁时释放。原模式仍逐项绘制。
2. **跳过透明区域。** 候选模式按实际字形范围裁切源纹理和接触遮罩，保留足够边距；绘制目标和像素密度不变。水膜场只跳过确定无接触的外侧列。
3. **复用精确噪声散列。** 缓存整数网格的梯度散列，保留逐像素插值和当前相位；资源能力不足时使用原计算。
4. **分离显现与接触遮罩。** 新文字逐字显现时，已显现文字继续保持水膜；未完成的字符不提前进入接触场。两种遮罩使用独立纹理。

未降低 DPR 上限、像素总量上限、模糊半径、色散采样数、曲面精度或水膜场分辨率；未通过限帧改善数据。

## 性能实测

环境：本机 Ego Lite Chromium，正式阅读组件；宽屏 1440×900，移动视口 390×844，设备像素比设为 2，渲染器沿用原像素预算。使用仓库内已审核的离线经文。快滚采用原生输入，每轮三次向下/向上各 550 CSS 像素、速度 1500 CSS 像素/秒。

| 场景 | FPS | 95% 帧间隔 |
| --- | ---: | ---: |
| 合并绘制前，宽屏快滚，第 1 轮 | 9.52 | 201.7 ms |
| 合并绘制前，宽屏快滚，第 2 轮 | 8.86 | 251.3 ms |
| 合并绘制后，开发版宽屏快滚，第 1 轮 | 27.15 | 50.8 ms |
| 合并绘制后，开发版宽屏快滚，第 2 轮 | 26.82 | 50.4 ms |
| 最终生产构建，宽屏快滚 | 26.28 | 50.0 ms |
| 最终生产构建，宽屏静置稳态 | 29.17 | 49.8 ms |
| 最终生产构建，移动视口快滚 | 26.29 | 50.1 ms |

诊断时临时关闭逐字模糊，能将约 9 FPS 提升至约 26 FPS，确认主要瓶颈；交付实现保留模糊，使用合并绘制获得收益。上述结果是本机环境实测，不能解释为所有设备达到 60 FPS。尺寸变化后的初始化样本未作为静置稳态结果。一次空载 RAF 采样超时，未纳入结论。

## 画质与交互

以任务开始前保留的代码作为画面对照，使用同一字体、经文、视口、滚动位置和固定噪声相位，读取最终画布像素：

| 对照 | 1440×900 最大通道差 | 390×844 最大通道差 |
| --- | ---: | ---: |
| 原模式与任务前原模式 | 0/255 | 0/255 |
| 候选模式与任务前候选效果 | 2/255 | 2/255 |
| 逐字显现及高亮：合并与逐项绘制 | 2/255 | 2/255 |

另对宽屏滚动位置 110、450、900 分别比较，最大通道差均为 2/255，无像素超过该值。已查看宽屏、移动尺寸及显现中画面。逐字显现的对照使用同一套已修正的独立遮罩，以单独验证合并绘制的影响。

浏览器通过项：

- 正式生产阅读器观测到入场和逐字显现从 `entering` 到 `settled`，同时保留待进入状态。
- 候选开关保持阅读区实例、暂停状态、滚动位置、阅读路径和历史长度。
- 离线「养心」分支成功生成子阅读路径；切换模式后浏览器返回，恢复父路径及其候选模式。
- 普通入口为 `current`，菜单只有「添一念」「温故」。
- 宽屏与移动尺寸均无横向溢出。
- 减少动态效果时，原生文字可见、透明度为 1，无模糊或变换。
- WebGL 上下文丢失时原生文字可见；恢复后重新绘制候选模式。
- 生产验证无运行错误，未发出真实模型请求。开发验证中一个无离线关系的普通词触发的远程尝试已被测试层拦截；成功分支使用明确的离线关系。
