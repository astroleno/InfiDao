# Flow 30 FPS 联合分析：证据校正版

日期：2026-10-23。原报告的并行分析结论已逐项对照当前源码和原始验收记录修订。本文保存有效线索与证据限制；[统一执行方案](../plans/2026-10-23-001-fix-flow-60fps-execution-plan.md)负责后续任务顺序和状态。

## 1. 核心结论

- 网页 FlowStream 直接用 RAF 驱动绘制，没有经过 WheelRenderer.start 的 32ms 节流。
- 原报告对应控制页约 29.69 回调 FPS，本轮结束约 29.20，均不能验收 60Hz；历史控制曾恢复约 60Hz，因此不判定 Ego 恒定锁 30。
- 候选短内容仍约 29–30 回调 FPS；首次生成已优化，旧候选长历史秒级间隔在本轮新旧构建上均未复现。普通模式仍约 3–5 FPS，现有证据尚不能确定完整因果链。
- 光学层已使用 WebGL，焦散和粘合实现已存在；是否达到目标体验须按具体版本与场景验收，不能由 shader 存在或历史像素对照替代。
- 稳定 60 FPS 尚未完成，继续在获批架构内定位和优化有依据；无需据此直接更换引擎。

## 2. 已核实的当前实现

| 内容 | 事实与影响 |
| --- | --- |
| 可见索引、失效分离、源范围与回收 | 已实施；不能再次列为“未开始” |
| 普通 current 模式 | shape.liquid 门控使其仍走 Canvas 字形源 + WebGL 光学；可独立评估 GPU 适配 |
| 候选测量路径 | 最终桌面 891 帧、手机 884 帧全为 cached，旧 Canvas 仅 4 字节；不能用普通路径解释其约 29 FPS |
| 滚动更新 | 基础字形复用，但位置、模糊、透明度、显现与前景归属会变化；玻璃结果不能整帧无条件复用 |
| 首次行缓存生成 | 本轮已用原生覆盖合成去除两次整块像素读取；接触梯度只上传变化行，实测见执行记录 |
| 水膜更新 | liquid-live 按既定设计持续变化；减少无效工作须保留该动态 |
| 噪声纹理 | 已有格点/整相位身份判断，并非每帧无条件重传 |
| 光学范围 | 已有源绘制及水膜横向 scissor；后续透射与最终曲面的安全范围仍未完成 |

## 3. 实测数据的适用范围

本轮开始前的最终构建 e3d8aa14afe348a3（后续 3f42a54778e65474 结果见[执行记录](2026-10-23-flow-60fps-execution.md)）：

| 场景 | 回调 FPS | CPU P95 |
| --- | ---: | ---: |
| 桌面静置 / 首次快滚 / 重复快滚 | 29.60 / 29.70 / 29.50 | 1.4 / 12.3 / 3.9ms |
| 手机模拟静置 / 首次快滚 / 重复快滚 | 29.45 / 29.40 / 29.05 | 1.7 / 19.3 / 6.9ms |

控制页 29.69 FPS；长历史有效轮次仍有约 1 秒间隔。手机 19.3ms 不能列入“桌面实测”列。GPU 整段 6.565–18.786ms / 9.105–15.806ms 来自中间构建；分通道结果不足以可靠归因。

历史宽屏 20.81 与手机视口 59.99 FPS 来自不同时间条件，原记录已说明环境波动；不能称为像素吞吐主导的“铁证”。历史应用内浏览器三轮静置约 60 FPS 不代表最新完整页快滚达标。显示链 FramePresented 未保留页面表面归属，不是本页实际呈现认证。

## 4. 对原建议的裁定

| 原建议/结论 | 修订后处理 |
| --- | --- |
| 换环境后再做所有工作，否则数据无效 | 先校准约定的 Ego；校准失败仍可做同条件成本与画质对照，实际 60 FPS 保持未通过 |
| 删除 liquid 门控即可解决低帧率 | 普通模式独立优化；需覆盖原手机 9px 模糊、颜色和文字移交，现 GPU 前景上限为 8px |
| 滚动仅更新 uniform，整帧模糊/玻璃复用 | 不采用这一简化；按真实依赖减少重建和受影响像素 |
| 透射/水膜/最终通道按范围裁切 | 保留方向；证明保守影响范围、中性色及旧新清理后实施，收益待实测 |
| 水膜固定降到 30Hz 并插值 | 未纳入本轮等价优化；已有插值仅针对接触遮罩，不能证明整个场降频无损 |
| 模糊量化 0.5px、去掉背景模糊、中心全 Canvas | 改变视觉或原生行为，不能作为默认无损修复 |
| 新词预备/分帧 | 保留线索；先去除可避免的同步像素工作，再按证据设计有界队列 |
| 每词必定强制一次布局、透明词必定双重栅格 | 降为待验证假设；需触发次数、失效与绘制追踪 |
| 默认无候选水膜属于缺陷 | 默认关闭是用户明确要求，继续保持 |
| 增加入水进度 uniform | 属新增动效设计，不混入本轮性能修复 |
| 预计 CPU 减半、GPU 降 40–50% | 删除未经同条件实测支持的收益承诺 |

## 5. 接下来的工作

本轮文档和基线、分模式诊断、新行覆盖合成、梯度增量上传、布局通知合并及部分安全绘制范围已落地；422 项 Flow + 124 项共享逻辑测试和 52 组画面对照通过。耗时对照存在电源状态变化的混杂因素，不据此承诺收益。下一步先处理普通模式滤镜范围的等价性与停顿，再继续长历史和剩余光学范围；保留原画质、入场、逐字显现、原生交互及候选默认关闭。

正式验收必须同时覆盖控制校准、完整页、30 秒 × 5 轮和归属明确的实际呈现；不能将“列出待办”视为已覆盖五项未通过项。新实验及不成立假设写入[执行记录](2026-10-23-flow-60fps-execution.md)。
