# 水膜候选：绘制节奏调查与后续优化

日期：2026-10-23。接续 [上一轮候选模式验证](2026-10-23-flow-motion-candidate.md)。本轮基线为上一轮交付后的代码，保留现有入场、逐字显现、画质及默认关闭行为。未提交、推送或部署。

## 绘制节奏结论

**没有证据表明当前阅读器被代码固定限制在 30 FPS；测试环境的绘制节奏确实会变化。**

- 本机 Apple M4，内置屏幕 60 Hz，低电量模式关闭；Ego Lite Chromium 154，ANGLE Metal。未修改系统或浏览器的限帧设置。
- 在可见、获得焦点的页面上，分别绘制简单的 DOM 位移、160×160 的二维画布和 WebGL 清屏。第一轮均约 **29.5–30.0 FPS**，每帧 JavaScript 工作低于 0.05 ms。
- 后续同样的控制场景恢复至 **约 60 FPS**。未修改的正式阅读器在同一次测试中也出现约 21–60 FPS 的变化。
- 空白页面不产生绘制时，一度仅每秒回调一次；因此不使用空载 RAF 作为应用性能基线。
- `FlowStream` 由自身的 RAF 调度直接调用 `StreamGlass.draw()`；没有经过旧轮播渲染器的 32 ms `start()` 节流。

这修正了调查初期“约 30 FPS 上限”的判断：它是当时测得的绘制节奏，并非恒定上限。当前证据不能确定环境内部变化的具体原因，也不能把阅读器所有慢帧归因于环境。

## 保留的改动

1. **跳过空接触样本的水膜计算。** 13 个采样位置和所有非零样本保持原样；仅在接触 alpha 严格为零时跳过后续肩部、收颈和体积运算。没有新增透明度阈值。
2. **跳过无笔画区域的显现噪声计算。** 先读取原有中心及四邻域字形，确认五个 alpha 全部为零才返回，保留原湿边范围和噪声公式。
3. **复用未变化的逐字显现数据。** 同一不可变文字列表只改变水膜相位时，不再重绘、上传显现数据纹理。显现进度、字体或尺寸变化时重新生成；原有上下文恢复流程也会重建数据。

未调整动效时序、采样数、模糊、色散、曲面精度、DPR 或像素预算。曾试验提前跳过必定未附着的区域，但其收益不稳定且产生少量像素差异，已撤回。

## 可重复的局部收益

### 显现进度不变、水膜继续流动

在同一页面交替绘制基线与候选，使用相同的真实字体、文字布局、固定显现进度和水膜相位；每种实现排除预热后各测 64 帧。这是局部场景的 `StreamGlass.draw()` CPU 耗时，不代表整个阅读器快滚速度。

| 视口 | 基线 CPU / 帧 | 优化后 CPU / 帧 | 降幅 | 显现数据上传 / 64 帧 |
| --- | ---: | ---: | ---: | ---: |
| 1440×900 | 0.855 ms | 0.198 ms | 76.8% | 64 → 0 |
| 390×844 | 0.781 ms | 0.187 ms | 76.0% | 64 → 0 |

同一区间内，显现数据矩形绘制分别由 8,896 次和 7,168 次降至 0。这里减少的是重复工作，显现进度有变化的帧仍完整更新。

### GPU 着色

在同一 WebGL 上下文中按 A/B/B/A 顺序切换前后着色器，保持相同输入，每种实现各测 64 帧。滚动场景中，水膜场单次绘制的计时均值下降约 6–9%，所有绘制调用的计时之和下降约 2–4%。这些是带计时探针的局部结果；GPU 调度有波动，绘制调用计时之和也不等同于整帧耗时，不能直接换算为 FPS 增幅。

## 正式阅读器实测

使用本地生产构建、仓库内离线经文的同一组 6 个阅读片段。视口分别为 1440×900、390×844，模拟设备像素比为 2；实际画布仍为原预算的 1789×1118、585×1266。每轮三次往返滚动，各方向 550 CSS 像素，速度 1500 CSS 像素/秒，分别使用鼠标和触摸输入。

| 场景 | 本轮修改前 | 本轮修改后 |
| --- | ---: | ---: |
| 宽屏快滚，三轮 FPS | 34.88 / 26.21 / 21.00 | 22.46 / 21.97 / 21.55 |
| 移动视口快滚，三轮 FPS | 20.55 / 20.56 / 29.09 | 34.33 / 33.89 / 33.54 |
| 宽屏静置 FPS | 20.81 | 21.29 |
| 移动视口静置 FPS | 59.99 | 60.05 |

前后生产测试并非同时进行，且环境控制场景已证明绘制节奏存在变化。**本轮不能确认整体快滚 FPS 稳定提升，也未证明宽屏稳定达到 60 FPS。** 上表保留完整结果，避免仅选取较快的一轮。局部计算与上传的减少由独立交替测量确认。

## 画质与功能验证

以本轮开始前保存的代码为基线，对最终实现读取最终画布 RGBA：

- 2 种尺寸 × 3 种模式（原模式、水膜候选、焦散对照）× 2 个滚动位置 × 2 种显现状态 × 4 个噪声相位，共 **96 组比较，所有像素通道差均为 0**。
- 包含逐字进度 0、0.25、0.5、0.75、1、高亮、连续相位缓存、整数噪声边界及接近循环边界的相位。
- 已查看生产构建的宽屏与移动尺寸画面；均无横向溢出。
- 正式阅读器观测到入场与逐字显现的 `waiting`、`entering`、`settled`、`paused` 状态。
- 候选开关保持阅读区实例、滚动位置、阅读路径和历史长度。
- 普通入口仍为 `current`，菜单仅含「添一念」「温故」，候选继续默认关闭。
- WebGL 丢失时原生文字可见，恢复后重新绘制；减少动态效果时文字透明度为 1，无模糊与变换。
- 浏览器验证无运行错误，未发出真实模型请求。
