补召要求阅读范围启用诗词，并在当前发布包核实作品版本、原文段 ID、文本散列及引文和选词坐标。候选优先取同段内命中计划词的未读诗句，同段无命中时再查同一作品版本紧邻的下一段与上一段。三段都无逐字命中时，取距来路引文最近的合格未读诗句，等距时优先后句。每次最多补入一个候选，长诗测试用《憶昨詩示諸外弟》的真实分段验证段内坐标。释义点词、引文范围外的点读、关闭诗词、候选均已读、切换阅读范围和版本或坐标无法核实的情况沿用普通召回。非图链模式继续排除来路段 ID，既有准备引文保持先交付原句的行为。摘窗记录和模型输入均使用实际截取位置，以正确处理重复字串。

浏览器在点词分支过期时会携带原文引文和选词坐标重新开启阅读。三个读点也通过了没有父会话的重新开启测试。会话在首次交付前中断时，可用链 ID 恢复既有计划与经核实的选词身份。选词身份只保留到首次完成，普通开篇和续读沿用原流程。补召计入检索时间，计时仍在摘窗前结束。
