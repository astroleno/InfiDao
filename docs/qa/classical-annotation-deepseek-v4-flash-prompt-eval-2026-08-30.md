## 失败模式

v3 解决了 v2 最突出的虚构数值阈值问题，但把“权益、安全、拒绝、可逆方法”写成了通用脚手架，出现新的系统性过拟合：

- 在目标排序、远虑、制度、环境塑造等无关场景反复插入拒绝或安全边界，挤占问题核心。
- case 6（目标过载）均分 17.889，7 个 hard-fail 评审；常遗漏阶段主目标、边际收益与机会成本。
- case 11（善意与制度）均分 17.444，9 个 hard-fail 评审；常遗漏善意、制度与执行共同构成持久支持。
- case 14（环境塑造）均分 15.889，6 个 hard-fail 评审；常遗漏环境设计、反馈机制与人的持续学习过程。
- 相对稳定的 case 是 12（23.889）、13（23.444）、8（23.111），说明模型能处理边界清楚的互惠、自强与关系问题，但对需要同时保留多个结构要素的题目容易降格成通用决策模板。

## 后续实验建议

下一轮不应继续堆全局禁令。更合理的方向是把提示词拆成“固定双向语义骨架 + 根据问题类型选择的少量约束”，让拒绝/权益、证据不确定性、制度执行、机会成本等规则仅在相关 case 激活；再建立新的 dev/holdout，避免用本次 golden12 继续调参。达到门槛前不修改生产提示词。
