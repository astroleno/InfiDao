## 3. 已落地的代码

1. **新行覆盖合成。** `StreamGlyphCache.cell` 用不透明黑底、原字形覆盖和蓝通道下划线合成同样的 RG/B 掩码，去除两次整行像素读取、像素循环和整行回写。CSS 颜色首次解析的 1×1 读取保留，内存预算、字形身份、回收和回退不变。
2. **接触梯度增量上传。** 比较实际字节，只上传首末变化行之间的区域；完全相同时不上传。每帧接触计算和材质相位保持。
3. **诊断及布局通知合并。** 显式探针记录布局原因/次数/耗时、绘制耗时与缓存阶段。正常路径不做阶段计时。字体和尺寸通知在下一帧合并，尺寸相同的通知跳过；内容及恢复布局仍同步。短内容布局次数由本轮中间版 6 次减至最终版 4 次。
4. **保守绘制范围。** `activeWidth` 与纹理容量的 UV 映射分开，源文字和水膜使用实际有效宽度。水膜中央使用 shader 本来的精确中性色，只绘制两侧折叠带并保留一像素保护边界。每帧先清理旧场。两次透射和最终曲面仍完整绘制，未声称已完成所有光学范围优化。

`rowsMs` 包含新字形、新单元和图集上传的 CPU 时间；这些嵌套数据不可相加，上传计时也不是 GPU 完成时间。帧级 `sceneMs` 是总 CPU 扣除绘制调用，包含该帧发生的布局重测；布局另有次数和耗时记录。

### 普通模式：未通过

最终普通模式仍为原 Canvas 字形路径，无候选水膜。桌面首次/重复快滚约 3.07/3.06 FPS，最长间隔约 1017/783ms；长历史顶部/中部/重复约 2.80/3.84/3.61 FPS。顶部轮次包含一次 110ms 尺寸重测，后两轮 CPU P95 仅 4.4/4.2ms，仍明显停顿。

对普通模式长历史另取约 7.37 秒、只保留目标页面进程事件的 trace：绘制回调约 4.85 FPS，CPU P95 6.8ms，最大回调间隔 1016ms；主帧单次最长 25.8ms、Paint 最长 2.49ms、Layout 最长 3.22ms。BeginFrame 有 4 次超过 500ms 的间隔，TimerFire 最大间隔约 151ms。此记录排除了“整秒都在一次 JS/布局中”的解释，尚不能区分全部 GPU、合成与环境原因。

### GPU

最终整段 10 个异步查询均未 disjoint，且未超过查询可用前的墙钟时间：静置 2.628–4.594ms，滚动 9.845–18.049ms。首个滚动查询对应 CPU 54.2ms 峰值也保留；查询插桩本身可能扰动提交，不能与未插桩的 CPU 表格直接混算。
