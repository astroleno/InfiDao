# 点词等待、停靠与到达验收

固定样本从《论语》「其恕乎！己所不欲，勿施于人。」点「恕」，接到《中庸》「所求乎朋友先施之，未能也。」。页面使用当前经文库的文本、词位和字体。测试服务逐次发出已核引文、已放行回响及完成信号，可以分别观察各状态。 [实施方案](../plans/2026-11-25-flow-arrival-and-plan-pairs.md)

| 状态 | 可观察结果 |
| --- | --- |
| 停驻 | 点击空白后暂停在原经文。 [截图](evidence/2026-11-26-flow-word-arrival/parked.png) |
| 等待 | 只显示所点词和「停止」，新引文与回响尚未出现。 [截图](evidence/2026-11-26-flow-word-arrival/waiting.png) |
| 停靠 | 已核引文在屏外时只有一条状态，含「去读」与「停止」，两个操作区域均至少 44 × 44 像素。停止后可在原位继续补全。 [截图](evidence/2026-11-26-flow-word-arrival/docked.png) |
| 到达 | 按「去读」后滚到引文并把焦点交给它。已放行回响立即可读，仍在补全时可以停止。 [截图](evidence/2026-11-26-flow-word-arrival/arrived.png) |

有 WebGL 时，停驻且已核目标在视口内，折边收至最多 8 CSS 像素。浏览器将新回响第一行放在距屏底约 64 像素处，验证原字无折转、透明度为 1、无模糊。读者继续滚动后恢复原有移动材质。判断「去读」同时考虑实际视口、折边和停靠区占位。视口下移、长引文仅露出末尾及焦点交接由定向测试覆盖。

Chromium 和 WebKit 共走六条浏览器路径，包括 390 × 844 与 320 × 568、减少动态、无 WebGL、屏外停止后继续补全及引文到达后的失败反馈。两个回退场景的引文均从约 73% 的屏高处开始，完整在屏内，没有显示「去读」。合成响应只用于交互、清晰度和时序验收。iPhone Safari 真机待验。 [浏览器检查记录](evidence/2026-11-26-flow-word-arrival/checks.json)
