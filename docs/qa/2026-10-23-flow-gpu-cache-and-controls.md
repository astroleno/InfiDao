# 阅读交互与 GPU 字形缓存验证

日期：2026-10-23。接续本目录的动效候选及后续优化记录。数据来源为本地仓库、生产构建与本机 Ego Lite 实测；经文使用仓库的离线精选内容，未调用真实模型。没有提交、推送或公开部署。

## 当前结论

**交互和缓存回退检查通过；稳定 60 FPS 尚未通过验收。**

本轮把滚动时重复的文字栅格化、Canvas 模糊与纹理上传移到有界字形缓存和 GPU 绘制。局部对照证实重复工作减少，最终完整阅读页的实测仍低于目标。候选继续默认关闭。

此前“桌面静止约 21 FPS”不是稳定的设备性能结论：本轮在应用内浏览器对原生产版本连续测量三次、每次 10 秒，实际应用绘制分别为 60.00 / 59.90 / 60.00 FPS。随后应用内浏览器连接不可用，最终验证按用户要求使用 Ego Lite。不同浏览器、不同轮次的数据不能混为最终版本的验收结果。

## 已实现

- 点击阅读区域停驻；滚轮、单指纵向滑动、翻页键恢复流动。
- 选中文字、编辑输入、按钮的空格激活与程序设置滚动位置保留各自行为。减少动态效果时不自动恢复动效。
- 移除顶部停驻文字与省略号菜单入口，保留“六经注我”。右侧细把手支持点击或向左拖开；向右滑动、遮罩和 Escape 可关闭。
- 侧栏保留添一念、温故及候选开关，支持焦点循环、背景不可交互与关闭后焦点返回。
- `StreamGlyphCache` 根据字体、字距、相对字形位置、字号布局和 DPR 管理最多两个 2048×2048 图集。字形以原有画布密度的两倍栅格化；没有降低输出分辨率。
- GPU 处理位置、透明度、焦点下划线、逐字显现元数据及原规格模糊。保留原玻璃、色散、曲面、水膜与入场实现。
- 字形和接触遮罩使用独立通道，显现元数据独立存储。仅相位变化的帧复用文字合成，滚动不会重新上传已有字形。
- 不支持的缩放、模糊或布局沿用原 Canvas 路径。缓存错误会在当前实例内停用缓存；尺寸变化或上下文恢复可重新创建。
- 着色器仅提前返回数学上必定未附着的区域。八组 RGB 色散采样、像素预算及曲面规格不变。

## 性能证据

### 同一 Ego Lite 页面内的局部对照

使用真实阅读内容的字体和位置，1440×900 视口、DPR 2；实际光学画布仍为 1789×1118。固定往返范围 140–690 CSS 像素，速度 1500 CSS 像素/秒。

| 实现 | 局部快滚 FPS | 文字绘制 CPU 平均值 |
| --- | ---: | ---: |
| 本轮开始时冻结的 Canvas 基线 | 17.30 | 12.35 ms |
| 最终 GPU 缓存，第 1 轮 | 29.12 | 4.60 ms |
| 最终 GPU 缓存，第 2 轮 | 29.12 | 1.75 ms |

CPU 样本为每轮预热后的 20 次调用，FPS 为另一个持续动画区间，二者不是同一种测量。这里使用隔离的绘制器，不代表完整阅读页帧率。

早期 GPU 原型在应用内浏览器的同类局部场景达到约 58 FPS；它不是最终生产阅读页的结果，因此不能据此声称已达到 60 FPS。

### 最终生产阅读页，Ego Lite

生产版本：`898746c95eaba3a4`。每种尺寸快滚三轮，每轮 5 秒；另测静置 5 秒。记录实际产生光学绘制的应用帧，排除每轮前五帧，保留后续慢帧。自动滚动保持暂停，以程序设置滚动位置驱动可重复的速度与范围。

| 视口 | 快滚三轮 FPS | 静置 FPS | 实际画布 |
| --- | --- | ---: | --- |
| 1440×900 | 20.97 / 25.86 / 25.66 | 29.17 | 1789×1118 |
| 390×844 | 27.74 / 27.95 / 21.23 | 29.08 | 585×1266 |

同期、同页隐藏阅读内容后绘制可见的 160×160 简单画布，测得 29.60 FPS。页面报告可见且获得焦点。这说明该轮受浏览器或环境绘制节奏影响，但不足以把阅读器所有慢帧归因于环境；完整快滚仍有额外开销，部分轮次出现约一秒的间隔。没有修改系统或浏览器限帧设置。

**60 FPS 是仍未完成的验收项，未延期，也未按达标交付。**

## 画质

对冻结的 Canvas 基线与 GPU 缓存作相同输入对照：桌面 5 组、移动尺寸 4 组，覆盖不同滚动位置、相位、焦点和逐字进度 0 / 0.25 / 0.5 / 0.75 / 1。

- 最终输出 RGB 平均绝对差为 0.40–0.89 / 255；单点最大差可达 242，主要位于笔画与显现边缘。
- 已查看桌面及手机对照图，未见缺字、裁切或光学效果丢失。文字栅格化和模糊实现变化带来细微边缘差异，**不宣称逐像素一致**。
- 原有入场与显现的 waiting、entering、paused、settled 状态在生产页均有记录。
- 未降低 DPR、输出像素预算、色散采样、模糊规格或曲面精度。
- 移动尺寸为 Chromium 模拟，未覆盖真实 iPhone Safari 或微信内置浏览器。

## 交互与恢复

- 桌面点击停驻、滚轮恢复、PageDown 恢复通过。
- 触摸向左打开侧栏、向右关闭、纵向滑动恢复通过。
- 遮罩、Escape、Tab 循环、选文、输入保护与程序滚动保护通过。
- WebGL 丢失时原生文字仍可读；恢复后重新进入缓存路径。
- 减少动态效果正常；尺寸改变后重新建立缓存，无横向溢出。
- 普通入口为 `current`，使用 Canvas 路径；侧栏只有关闭、添一念、温故。显式候选入口才显示水膜开关。
- 最终测试无页面运行错误，无真实模型请求或被拦截的模型请求。
